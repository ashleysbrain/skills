# Accuracy Lock — Four Research Objects (rev J, 2026-08-02)

## Research Objects (four, not three — updated 2026-08-02)

### Neuromorphic (grounded)

- Field: neuromorphic computing / engineering.
- Core idea: electronic systems that share organizational principles with neural systems (neurons, synapses, spikes, analog/event-driven physics).
- Canonical origin: Carver Mead; late 1980s work; 1990 *Neuromorphic Electronic Systems* (Proc. IEEE lineage).
- Modern forms: SNNs, neuromorphic chips, memristive synapses.
- Acceptable public shorthand: "mimics the neuron" / neural scale.
- Incorrect: equating neuromorphic with transformers, chatbots, or a cracked LLM die.

### Model-centric agent AI (product object)

- One LLM (or thin router) as intelligence core, tools bolted on.
- Valid critique: single channel; brittle under load; weak multi-system regulation.
- Correct left panel for software architecture comparison.
- Caption claims are rhetorical teaching contrast, not a theorem about all AI.

### Common multi-agent (updated 2026-08-03 — adversarial audit rev K)

- Several agents + tools. More parts than model-centric.
- **Agents DO share context** (AutoGen GroupChat, LangGraph shared state, CrewAI context passing). Do NOT call them "siloed" or claim "no exchange."
- The gap is exchange PATTERN: they do task-routing and context-passing, NOT structured specialist re-evaluation (R1 independent → handoff → R2 informed → synthesis).
- More agents does NOT equal organism-scale regulation.
- Name it "common multi-agent" not "typical" or "all."
- Do NOT use derogatory labels like "stitched-together." Use "combined result from separate agent outputs."
- LangGraph is the closest existing framework to Physiomorphic. The distinction is that Physiomorphic treats the exchange pattern as foundational architecture, not a configurable option.

### Physiomorphic AI (field claim)

- Named at Divinity Science by the principal Williams.
- Organism-scale multi-agent structural isomorphism.
- Public teach modules: Specialists, Coordination, Regulation, Recovery, Defense, Timing.
- First organism: the operator agent. No consciousness claim.
- Is technology. Performance claims are thesis language unless benchmarks shown.
