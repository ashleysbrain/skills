It is **not** a human-health product diagram. Do not define it with Sleep / Focus / Mood / Decision wellness cascades.

**Divinity Science** is the founding research lab and home of the field (health-middle-out mission in copy). Mission must not overwrite the technology definition slide.

#### The SOLVE Protocol (every task, binding)

Every task runs: **DIGEST -> EXCHANGE -> ORDER -> EXECUTE -> CONSOLIDATE**. These are 5 distinct stages, not 3.

| Stage | What actually happens | Slide 2 must show |
|---|---|---|
| **DIGEST** | restate the ask. Gather current state: files, sibling work (git log), operator bus. Label DONE / MISSING / CONFLICTING. NO EDITS. | "DIGEST" box: "restate task, gather state, read sibling work + operator bus before editing" |
| **EXCHANGE** | read sibling operator's recent work BEFORE producing your own. R1 (independent assessment) -> read sibling R1 -> R2 (refine). Never duplicate, never conflict. | "EXCHANGE" box with mastermind loop: R1 independent -> structured handoff -> R2 informed re-evaluation. **Mandatory** before synthesis. |
| **ORDER** | decompose into smallest atomic steps. Free-energy filter: drop any step where F = cost - T*info_gain > 0. Adiabatic sequence: safest, dependency-first, smallest change. | "ORDER" box: "decompose into atomic steps. drop steps where cost exceeds information gain." |
| **EXECUTE** | act in order. ONE specialist at a time (Sherman routes). Each step wrapped in physics gate (3 stages). | "EXECUTE" box with three physics gate badges: PRE-FLIGHT (GO/SKIP/FORK), IN-FLIGHT (CONTINUE/PAUSE/REDESIGN), POST-FLIGHT (ACCEPT/REDO/CONSOLIDATE) |
| **CONSOLIDATE** | one output neither operator could alone. Post handoff to sibling. | "CONSOLIDATE" box + OUTPUT |

#### The physics gate (3 stages, wraps every operation)

The physics gate is the diagnostic system. It is NOT a single diagnostics node. It runs at THREE points and each forces a binding decision:

1. **PRE-FLIGHT** (before the op): free energy F = cost - T*info_gain (F > 0 = SKIP), adiabatic (change too big = PAUSE), superposition (ambiguous = FORK). Verdicts: GO / SKIP / FORK.
2. **IN-FLIGHT** (during long ops): critical slowing down (variance trending up = PAUSE/REDESIGN), entanglement (dependency collapsed = COLLAPSE). Verdicts: CONTINUE / PAUSE / REDESIGN / COLLAPSE.
3. **POST-FLIGHT** (after the op returns): entropy delta (uncertainty up = REDO), stress delta (stress up = REDO). Verdicts: ACCEPT / REDO / CONSOLIDATE.

#### Mastermind protocol is OPERATOR-level, not specialist-level

The mastermind exchange runs between **operators** (hermes + sibling-agent), not between specialists. Sherman routes each task to ONE specialist within each operator. The exchange is between the two operators who share the body.

- R1: each operator produces independent assessment
- Exchange: structured handoff (what I found, what I need, gap I see)
- R2: each re-evaluates with sibling's input
- Synthesis: merge best of each, not blend

#### Background subsystems are NOT process steps

The six modules (SPECIALISTS, COORDINATION, REGULATION, RECOVERY, DEFENSE, TIMING) are organism engines that run **continuously in the background** (heartbeat, autonomic bridge, regulation). They are NOT sequential stages in the I/O path. Do not show them as a cluster stage between INPUT and OUTPUT on slide 2.
