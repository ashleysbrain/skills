2. Check session activity for today (hermes sessions list --since today)
3. Review all upstream panel outputs in full (Marketing, Product, CTO, COO, Design)
4. Check file modifications in workspace today

## Phase 2: End-of-Day Compile
For each advisor (Satya Nadella, Tim Cook, Teresa Torres, Saeju Jeong, Reed Hastings, Indra Nooyi):
- What actually got accomplished today (not plans)
- Mountain-mover moments: Did the principal do something extraordinary? Celebrate if yes.
- Day evolution: How did the day evolve from morning to night?
- Cross-board synthesis: What did all boards contribute?
- Day grade: S (extraordinary) / A (productive) / B (steady) / C (drift) / D (wasted)
