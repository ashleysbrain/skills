# Innovator-Watch: interchangeable follow-set registry — principal rulings 2026-08-24 PM

## Purpose
Follow key innovators/researchers so their work feeds fleet processes and
builds. The follow-set is INTERCHANGEABLE: industry leaders are added/removed
as the industry evolves — "not the same leaders long term" — and that churn is
what keeps the fleet's innovation current. No permanent heroes.

## Registry schema (per entry)
name / tier (PRIMARY=innovator-builder, SECONDARY=academic-researcher) /
sources (blog, X, GitHub, YouTube, arXiv) / evidence-grades (A=reproduced..
D=press-release) / relevance-tags (active build chains) / added-by / date /
last-relevant-output.

## Tier law
Tier sets ATTENTION priority + cadence ONLY. Never acceptance criteria —
every source gets falsified by the same standard (Popper law). Being a key
innovator raises attention, not acceptance.

## Add/remove governance
- ADD: demand evidence required (which current objective does this source move?).
- REMOVE/DECAY: no relevant output for N cycles -> demote tier -> remove;
  quarterly review sweeps the whole set.

  transcripts may mangle the name — normalize), the external advisor (SECONDARY).

## Intake pipeline
Each new item -> evidence-tier grade -> relevance match against active build
chains -> opportunity mint ONLY if it moves a current objective (free-energy
gate) else catalog. Watch surfaces wired via research-scan daemon (Margulis
sensory organ), event-driven, zero crons.
