## VALIDATION GAUNTLET (consensus across 4 elite reviewers)

### 1. Null Model
What does a random abstract-to-pathway mapping produce? If the operator agent's constellation is indistinguishable from random, the structure is meaningless.

### 2. Baseline Comparison
What does BERT/GPT/LDA produce on the same 316 abstracts? If the operator agent's map matches standard NLP clustering, the biological architecture adds nothing. The value proposition must be: "what does biological architecture see that standard embeddings conceal?"

### 3. Stability Analysis
Run the same 316 abstracts twice. Same constellation? If not, the mapping is noise.

### 4. Ground Truth
Does the constellation reproduce 5-10 known theoretical relationships? (IIT vs GWT, FEP vs predictive processing, HOT vs IIT)

### 5. External Validation
Does constellation proximity predict co-citation, expert similarity, or prediction-space overlap?

### 6. Citation Network Overlay (THE critical move)
Overlay the architectural-resonance map with a citation network map. Where they DIVERGE (architecturally resonant but not citation-connected) = true structural holes. Without the overlay, it is clustering. With it, it is a structural hole discovery instrument.
