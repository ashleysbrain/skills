# Report quote policy and flow layout notes

This reference captures the report-rendering lessons that matter for future 8D PDF output.

## Hero quote policy
- Use only exact, attributable quotes from a fixed bank or verified source.
- Show the author alongside the quote.
- Do not paraphrase, style-match, or invent motivational quotes.
- If a quote cannot be verified, omit it rather than approximating it.

## Quote selection process
1. Classify the report mood from the Overview and Psychological read.
2. Pull only from the approved fixed quote bank for that mood.
3. Prefer quotes whose tone matches the user's current state: steadier for recovery days, more activating for momentum days, more principle-driven for balanced days.
4. Verify the quote text and attribution are exact before rendering.
5. If multiple quotes fit, rotate deterministically so the report stays fresh without inventing new language.
6. If no quote clearly fits, leave the quote box out rather than forcing a weak match.

## Flow-first multi-page layout
- Prefer breakable section blocks over forcing every card to stay intact.
- Let content flow across pages instead of creating large white gaps at the bottom of a page.
- Keep related content grouped, but allow natural page breaks when a card would otherwise waste space.
- Avoid making every card `page-break-inside: avoid`; use softer pagination controls when page density matters.

## Overview length
- It is okay for the Overview to use 2–3 short sentences when that improves understanding.
- Keep it compact and explanatory, not a paragraph wall.

## Recommendation framing
- Quick-win recommendations should be synthesized as if each 8D dimension has its own elite specialist brain.
- Keep any process language out of the visible report body; the report should go straight into the dimension cards with no generic blurb, prefatory explanation, or process note under the heading.
- Each dimension card should sound like a real specialist judgment for that dimension, not a generic wellness tip with a new label.
- Translate each specialist’s judgment into a practical next step for the user.
