# Report Style Calibration

This reference defines the final user-facing report feel for 8D Pattern Awareness.

## Style target
Combine three lenses at once:

- **Healing-centered**: the report should feel supportive, grounded, and non-shaming.
- **Clinical-clean**: the report should be crisp, restrained, and evidence-based without sounding medicalized.
- **Premium / executive**: the report should feel polished, intentional, and designed rather than template-generic.

## Visual rules for PDFs
- Avoid thick black section headers.
- Avoid oversized boxes and heavy fills.
- Prefer thin rules, soft dividers, or subtle label chips.
- Keep the page dense enough to scan quickly.
- Reduce vertical whitespace between sections.
- Use the Divinity Science palette: the specialist engine `#0D1B2A` as the base, the specialist engine `#FAF3E0` for background/soft surfaces, the specialist engine `#FFD700` only as a restrained accent, with optional QH Teal `#2DD4BF` or GD Deep Burgundy `#5C2333` only when the design needs a secondary signal; avoid generic yellow fills, red accents, black-heavy blocks, and centered narrow layouts.
- Prefer a single-column layout unless a split layout materially improves readability.
- Keep margins modest so the page feels deliberate, not airy.
- Do not put a separate label or section header above a plain-text footer; if a footer is needed, leave just the text.
- When confidence appears in the visible report, place it after the dimension recommendations block and after Watch-outs when Watch-outs are present so the specialist answers land first.
- The dimension recommendations block must be regenerated from the current day’s 8D signal map; do not reuse static canned bullets from the prior day.
- Each dimension card should show the current signal it is responding to and then the specialist read / next steps for that dimension.

## Content rules
- Do not replay the source note.
- Do not quote the user back to themselves.
- Do not add explanatory meta callouts about how the report was generated.
- Translate input into meaning, impact, and next steps.
- Include a psychological read, but keep it humane and non-diagnostic.
- Include what is still holding so the report feels balanced and useful.
- Make the next move tiny, obvious, and winnable.

## Anti-patterns
- black header bars
- long intro paragraphs
- generic reassurance
- too much vertical spacing
- repeated restatement of the input
- diagnosis language
- decorative filler

## Good end-state
A good report should feel like a sharp, compassionate brief that helps a person understand what is happening, what is getting in the way, what is still working, and what to do next — without making them relive the note.
