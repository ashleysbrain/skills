# Report layout density and palette correction notes

Session-derived notes for the 8D report surface.

## Layout density
- If the user says the page feels too condensed or centered, widen the content distribution across the full letter page.
- Keep line spacing readable, but do not stack the report into a tight middle column unless the user explicitly asks for a compact layout.
- The goal is a balanced page fill: readable, deliberate, and not airy.

## Palette correction
- Before recoloring, locate the documented brand palette and use that as the source of truth.
- Do not guess colors from memory when a reference exists.
- Do not substitute a generic bright yellow for a brand gold/neutral accent.
- When the user says a delivered color is wrong, treat that as a palette-source mismatch first, not a layout problem.

## Verification
- Confirm the rendered output uses the documented palette values.
- Confirm the page no longer feels over-condensed in the middle.
- Preserve the approved structure while applying the color/layout correction.
