## Selftest store isolation (CI red 32181576234 lesson)
New selftest checks added to a generator/gate that read module-level
CENSUS/CONTRACT paths go red on the CI runner (no production stores
exist there). Two-part guard:
1. Fixture-based checks only (build fake su/aliases dicts, never open
   prod stores).
2. Open-spy isolation proof inside the selftest:
```python
import builtins
_opens, _orig = [], builtins.open
def _spy(f, *a, **k): _opens.append(str(f)); return _orig(f, *a, **k)
builtins.open = _spy
try: build_entries(fixture_su, fixture_aliases)
finally: builtins.open = _orig
assert not any("connectivity.store" in o for o in _opens)
```

Gotchas that cost real time:
- Count assertions: match the card CLASS (`class="card "`), never a
  text mention (a "Location" grep once counted a note, hiding a real
  duplicate-card bug AND a real missing-card bug in one pass).
- A failed tool call may have ALREADY applied its edit (report object
  unreadable != apply failed). Inspect file state before retrying any

  instrument (`document.title = "MERGED=" + MERGED.length`), verify,
  then de-instrument in the same pass.
- Verify every renderer read of a replaced array: rewiring one
  `.forEach` while a `.filter` 40 lines later still reads the old
  array silently drops cards.

## Reusable finding classes (audit probes for any generated-registry hub)
1. **Declare-but-never-invoke**: functions defined, zero call sites
   (consent registry, egress allowlist). Probe: grep fn name, exclude
   definition lines. Prose claiming their enforcement = fabrication.
2. **Stats-vs-render divergence**: entries counted in header stats but
   never rendered (layer outside the renderer's layer table). Fix at
   generate time (layer whitelist) AND render time (render-or-reject).
3. **INHERIT violation**: no-opinion source entries fabricating
   status/note/layer that demote hand-verified truth. No-opinion
   entries must carry identity fields only.
4. **Prose-claims-vs-code** (PHI-class handling, token encryption):
   grep the codebase for the claimed mechanism; absent = strip the
   claim or mark "pending". Never leave the claim up.
5. **Hand-registry staleness**: hand entries contradicting census
   dims/status. Census wins by contract, but the hand side must still
   be cleaned (it survives as fallback).
6. **Port-coupled CORS**: an allowlist pinned to the base port breaks
   exactly when a port-probe wrapper falls back. Derive
   Access-Control-Allow-Origin from the request Origin within a
   loopback range.
