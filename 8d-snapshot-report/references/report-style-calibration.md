# Report Style Calibration

This reference defines the final user-facing report feel for 8D Snapshot Report.

## Style target
Combine three lenses at once:

- **Healing-centered**: supportive, grounded, non-shaming.
- **Clinical-clean**: crisp, restrained, evidence-based without sounding medicalized.
- **Premium / executive**: polished, intentional, designed rather than template-generic.

## Visual rules for PDFs
- Avoid thick black section headers.
- Avoid oversized boxes and heavy fills.
- Prefer thin rules, soft dividers, or subtle label chips.
- Keep the page dense enough to scan quickly.
- Reduce vertical whitespace between sections.
- Use the Divinity Science palette: deep navy surfaces with a crimson accent and restrained neutrals; avoid blue accents and yellow highlights.
- Prefer a single-column layout unless a split layout materially improves readability.
- Keep margins modest so the page feels deliberate, not airy.

## Content rules
- Do not replay the source note.
- Do not quote the user back to themselves.
- Do not add explanatory meta callouts about how the report was generated.
- Translate input into meaning, impact, and next steps.
- Keep the comparison language compact and concrete.
- Include what changed, what stayed stable, and what remains uncertain.
- Make the next move tiny, obvious, and winnable.

## Anti-patterns
- black header bars
- long intro paragraphs
- generic reassurance
- too much vertical spacing
- repeated restatement of the input
- diagnosis language
- decorative filler
- generated-report banners

## Good end-state
A good snapshot report should feel like a sharp, compassionate brief that helps a person understand what is happening, what changed, what is still working, and what to do next — without making them relive the note.
