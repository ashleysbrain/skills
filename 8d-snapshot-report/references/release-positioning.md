# Release Positioning

## Release identity
`8D Snapshot Report — support — v1.0.14 — 2026-06-29`

## One-line positioning
A baseline-aware 8D support skill that turns health check-ins into short, honest snapshot reports.

## Public promise
This skill answers four questions clearly:
- What is happening now?
- What changed versus the best available baseline?
- How strong is the comparison?
- What is the safest next step?

## Safety boundary
- Non-diagnostic
- No treatment advice
- No invented scores or hidden thresholds
- No trend claims from a single point
- Escalates urgent warning signs instead of continuing comparison

## Why it ships now
This release is useful on its own because it gives a clean public reporting layer before any deeper recommendation logic exists.

## Launch copy
8D Snapshot Report is the baseline-aware reporting layer for 8D health check-ins.
It keeps comparison honest, compact, and non-diagnostic while still being useful on its own.
