# Compact Blocked Report Layout Recipe

Use this recipe when the user wants a dense one-page PDF that feels grouped into blocks rather than a long airy page.

## What the user meant by "blocked together"
- Treat it as **stacked modules/cards** with shared width and rhythm.
- Keep sections visually separated, but not far apart.
- Avoid the essay look: no long uninterrupted paragraphs with large top/bottom whitespace.
- Aim for 1 title band + 1 intro strip + repeated section cards + a small footer strip.

## Visual recipe
- Page size: US letter.
- Margins: conservative but not cramped.
- Title: compact hero band at the top.
- Section blocks: same width, same padding, same border logic.
- Spacing: small gaps between blocks; avoid airy vertical spacing.
- Typography: short line lengths, slightly tighter leading than a standard report.
- Palette: deep navy / charcoal / white / one accent color.
- Avoid yellow highlights unless the brand explicitly uses them.

## Good defaults
- Use one strong accent for dividers or section labels.
- Put the most important interpretation first.
- Keep each block self-contained with a short header and concise content.
- Prefer readable density over visual emptiness.

## Verification
- Render to PDF.
- Confirm the delivered PDF is the exact file inspected.
- Check that the page reads as stacked modules, not floating paragraphs.
- Verify the layout remains legible on a phone-sized preview and on paper.
- If the document spills to a second page, confirm the spill is intentional and not caused by excess padding or overly large headings.
