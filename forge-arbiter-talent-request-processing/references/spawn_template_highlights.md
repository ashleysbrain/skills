# SPAWN-TEMPLATE.md Highlights

The spawn template located at `~/.sibling-agent/workspace/intel/agents/SPAWN-TEMPLATE.md` provides a standardized structure for defining new agent profiles. Key sections include:

- **Role Definition**: Title, reporting line, primary objectives.
- **Specialty & Expertise**: Required domains, certifications, experience levels.
- **Personality Profile**: Suggested MBTI, Enneagram, Big Five traits.
- **8D Wellness Scores**: Baseline targets for each of the 8 dimensions.
- **Model Tier**: Preferred LLM provider and model (e.g., anthropic/claude-sonnet-4-6).
- **Soul File Instructions**: Steps to create the agent's soul file and register in the agents database.
- **Journaling Requirements**: Initial journal entry format and compliance expectations.

When evaluating a talent request for a genuine gap, use this template to flesh out the new agent's profile before spawning.
