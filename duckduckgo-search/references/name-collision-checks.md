# Name collision checks

Use this when vetting a candidate brand, project, or agent name for prior use.

## Fast query pattern
Search both the exact candidate and close variants:

- `"<name>"`
- `"<name>" AI`
- `"<name>" agent`
- `"<name>" project`
- `"<name>" chatbot`
- `<name> ai project name`

## What to look for
- Existing AI products, agents, copilots, or chatbots using the same or near-identical name
- Strong collisions in adjacent domains like finance, trading, biotech, or enterprise software
- Whether the name is generic in one domain but distinctive in another

## Decision rule
- If the exact name already maps strongly to a known AI product or agent, treat it as high-collision.
- If results cluster around a non-AI domain but the word is still distinctive, note the domain and judge whether that collision matters for the user's brand.
- Always report the most relevant collision examples rather than just saying the name is "taken."
