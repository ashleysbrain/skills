# Agent roster scope

Session-derived guidance for OpenClaw roster work:

- Treat the **agent roster** as distinct from **cron/job wrappers**. Many fleet artifacts are scheduled automations, not agents.
- When the user asks to enrich or reposition the fleet, inspect the **active roster**, **inactive/archived roster**, and any **lineage roster** before deciding anything is missing.
- Prefer **augmenting existing agents** (skillsets, brains, roles, engine lanes) over recreating agents that already exist.
- Organize the fleet into **engine/lane sections** when useful, e.g. coaching engine vs self-healing engine, rather than flattening everything into one generic list.
- Current snapshot observed in this session: **76 total agent records**, **72 active**, **4 archived/inactive**.
