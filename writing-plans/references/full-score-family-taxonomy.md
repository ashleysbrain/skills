# Full Score Family Taxonomy

Session-derived guidance for health/scoring methodology exports and pitch materials.

## Keep these categories explicit
- **Final composites:** the top-line score the user sees.
- **Base scores:** the core domain scores before contextual modifiers.
- **Sub-scores:** the constituent scores that explain the composite.
- **Optional/contextual scores:** scores that appear only when relevant evidence exists for that day, user state, or product mode.
- **Confidence / certainty:** keep separate from the score itself.
- **Baseline / normalization:** show the operating baseline so the score does not read like a universal ideal.

## Wording pattern that prevents omission
Use phrasing like:
- "Full score family structure"
- "Sub-scores and optional contextual scores"
- "Always-on when data exists"
- "Optional/contextual when relevant"

## Export verification checklist
After generating a PDF or brief, extract the text and confirm the following are present:
- the score family map
- the sub-score labels
- the optional/contextual score labels
- the baseline / confidence language
- no accidental collapse into a single-number narrative

## Practical lesson from the session
A pitch pack can look complete visually while still omitting critical structure in the text layer. Always verify the exported text, not just the rendered pages, before handing the document to stakeholders.
