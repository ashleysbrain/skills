# Coaching-loop check-in prompts

Use when a user asks for an ongoing principal/advisor/panel loop and wants the system to monitor work over time.

## Good prompt shape
Prefer a broad intake window over a single-day recap unless the user explicitly asks for a narrow daily log.

Examples:
- "Over the last 7–14 days, what have you built, what has stalled, what is working, what is not working, and what do you want the panel to help you improve next?"
- "What changed over the last week, what moved forward, what got stuck, and what should the panel focus on tomorrow?"
- "Review the last 7–14 days, then tell me the top three principal moves, the blind spots, and the constraints I need to respect."

## What the panel should usually track
- principal effectiveness
- product progress
- research/publication momentum
- outreach / visibility / marketing
- team communication and culture
- health / energy / disability constraints that affect execution

## What to avoid as the first prompt
- A too-narrow yesterday-only question when the user has said they need broader context
- Generic advice that does not map to the user's actual work
- Prompts that omit constraints, energy, or disability load when those are material
- Questions that make the user repeat the same preferences every session

## Practical rule
If the user says they want an advisor board to "keep an eye on everything" or to provide daily guidance from a long context, treat the ongoing context window as part of the ask and ask for a richer time range.
