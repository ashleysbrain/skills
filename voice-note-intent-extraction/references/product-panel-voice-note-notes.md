# Product-panel voice-note notes

Session takeaways from a noisy voice note about product-advisor selection.

## Stable signal clusters
- Lean startup / MVP / experimentation: Eric Ries
- Design thinking / empathy / iteration: Tim Brown
- Jobs-to-be-Done / customer progress: JTBD framing
- Continuous discovery / learning loop: Teresa Torres-like signal
- Positioning / clarity: April Dunford-like signal
- Human-centered usability / accessibility: Don Norman-like signal

## Extraction rule
When a user asks for a deep dive on a voice note and the transcript is garbled:
1. Extract the recurring conceptual cluster, not the literal broken wording.
2. Separate actual ask from implementation noise.
3. If the ask is for a panel/roster, output the seats and the decision they should improve.
4. Keep STT artifacts out of the final advisor recommendation unless they add stable meaning.

## Recommended output shape
- What the user wants
- What the transcript is really about
- Advisor archetypes / lanes
- What is likely noise
- Confidence note
