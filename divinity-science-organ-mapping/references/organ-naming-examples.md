## Common Mistakes to Avoid

### ❌ Incorrect: Generic Naming
```
|| | |
|---|---|---|
| **Port** | 8110 |
| **Body System** | Visual Cortex (V1–V4, occipital + temporal lobes) |
| **Agent** | the specialist engine (Visual) |
```

### ✅ Correct: Scientist-Specific Naming
```
|| | |
|---|---|---|
| **Scientist** | the specialist engine (David H. Hubel) |
| **Port** | Part of Design Engine (8116) |
| **Body System** | Occipital cortex + ventral visual stream (fusiform gyrus) |
| **Agent** | the specialist engine |
```

```
|| | |
|---|---|---|

```
