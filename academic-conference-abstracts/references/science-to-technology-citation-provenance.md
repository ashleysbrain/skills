# Science-to-Technology Citation Provenance

Use this when an abstract translates established science into a new technical architecture and the submission requests references.

## Purpose

A bibliography must cover more than scientists named explicitly in the prose. It must trace every load-bearing scientific concept to its canonical source without padding the list with merely adjacent papers.

## Claim-to-source audit

Build a ledger before formatting references:

| Claim class | What to cite | Example canonical sources |
|---|---|---|
| Field being contrasted | Origin or canonical formulation | Neuromorphic systems: Mead (1990) |
| Architecture class | Foundational text | Multi-agent systems: Wooldridge (2009) |
| Biological organization | Foundational theory | Autopoiesis: Maturana & Varela (1980) |
| Regulation/control | Original and modern formulation when both matter | Ashby (1956); Sterling & Eyer (1988); Sterling (2012) |
| Mathematical mechanism | Primary formal source | Kuramoto (1984); Friston et al. (2006) |
| Modern framework review | Use only when it materially supports the exact claim | Friston (2010); Mashour et al. (2020) |
| Consciousness theory | Originator plus current operational treatment where needed | Baars (1988); Dehaene & Changeux (2011); Tononi (2004) |
| Interoception/body-consciousness lineage | Primary lineage papers/books | Damasio (1999); Craig (2009); Seth & Friston (2016) |
| Dynamical warning signals | Canonical empirical/theoretical source | Scheffer et al. (2009) |
| Methodological principle | Cite only if explicitly load-bearing | Popper (1959) for explicit falsification logic |
| Anatomical standard | Current authoritative edition | Standring (Ed.), Gray's Anatomy, 42nd ed. (2020) |

## Four coverage tests

1. **Named-author coverage:** every scientist named in the abstract has a matching reference.
2. **Concept coverage:** every load-bearing scientific concept has a canonical source even if no author is named in the prose.
3. **Reverse relevance:** every bibliography entry supports a specific sentence, method, or intellectual lineage. Remove decorative references.
4. **Primary-source quality:** prefer the original formal source; add a modern review only when it adds operational or contemporary context.

## Adversarial panel seats

Run separate reviewers for:

- **Bibliographic accuracy:** authors, year, title, venue, volume, issue, pages, DOI/ISBN.
- **Claim coverage:** missing scientific lineages and unsupported technical translations.
- **Relevance/padding:** references that do not support a specific claim.
- **Venue formatting:** whether the portal wants numbered, author-date, inline citations, or a separate references field.

A citation panel is not complete if it only checks DOI syntax. It must also test whether the selected paper is the correct source for the claim.

## Two-list method

Maintain two explicit lists instead of treating one bibliography as universal:

1. **Portal-ready claim bibliography:** the smallest complete set supporting every claim in the submitted abstract. Every entry must map to an exact sentence.
2. **Extended scientific lineage:** broader provenance for the poster, manuscript, and Q&A, including foundational works that shaped the architecture but are not directly invoked in the abstract.

When the user asks whether a count such as 13 references is “enough,” do not answer from count alone. Run the claim-to-source ledger. A list is insufficient when a load-bearing claim lacks provenance; it is padded when entries have no claim-level job.

## Oxford Abstracts delivery

Oxford Abstracts is a platform, not a universal citation style. The conference configuration controls whether references are included in the word limit and whether the field accepts rich text. Inspect the live form or conference instructions before choosing format.

If no style is specified:

- use a consistent author-date bibliography (APA 7 is a safe default);
- alphabetize by first author;
- provide DOI as `https://doi.org/...`;
- omit manual numbering unless the portal or conference asks for numbered references;
- produce a plain-text copy/paste version with no Markdown italics if the field strips formatting;
- verify whether references count toward the 500-word abstract limit before pasting.

## Anti-padding rule

More references are not automatically better. Expand beyond the named frameworks only when a source supports a load-bearing concept. A full provenance list may be longer than the inline citation set, but every entry must survive the question: “Which exact claim would become less defensible if this source were removed?”
