# Verified Citation List Template (2026-07-10)

Template for building a verified primary-source citation list when an abstract
names scientific frameworks by originator. Every citation must be verified
against publisher records (PubMed, Nature, Springer, Cambridge UP, Elsevier).

## Workflow

1. List every named scientist/framework in the abstract
2. `web_search` for each: "[author] [year] [framework name] [journal]"
3. Verify: correct authors, year, title, journal, volume, issue, pages, DOI
4. Format in consistent APA style
5. Save to `TSC-[YEAR]-REFERENCES.md`
6. If original + modern review exist, include BOTH

## APA Format Reference

```
Author, A. A. (Year). Title. *Journal*, Volume(Issue), pages. https://doi.org/xxx
Author, A. A. (Year). *Title* (edition). Publisher. ISBN
```
