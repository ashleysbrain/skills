# Launch Milestone Callout

Use this note when the user says the product has launched, shipped, or gone live.

## What to say
- Call the milestone out explicitly.
- Treat it as a real readiness transition, not a minor implementation detail.
- Name the artifact(s) that became live: agent, skill package, release files, demo path, or attached docs.
- If the product is now real, reflect that in the framing, scoring, or readiness narrative.

## What not to do
- Do not bury the launch under generic review language.
- Do not describe a live product as if it were still only a spec.
- Do not understate the milestone when the user is clearly celebrating a launch.

## Session lesson
The user corrected a missed callout: the 8D awareness agent, skill package, and release files were launched, and that should have been framed as the start of the product. Future launch reviews should surface this immediately and treat it as a major positive signal.
