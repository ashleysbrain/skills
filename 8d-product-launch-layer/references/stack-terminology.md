# 8D Stack Terminology

Use these labels consistently across the 8D package.

## Layer names
- **Source**: raw inputs, notes, transcripts, observations, baseline material
- **Engine**: the core awareness + snapshot logic that processes the Source
- **Release**: the packaged layer that presents the Engine as a shippable product
- **Vault**: private, premium, hidden logic that does not ship in the public release

## Plain-English rule
If a label does not help a new reader understand what the layer does, do not use it.

## Quick mapping for this family
- **8D Source** = intake and baseline material
- **8D Engine** = awareness + snapshot core
- **8D Release** = launch wrapper and public product surface
- **8D Vault** = private premium intelligence
