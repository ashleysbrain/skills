# Long-Term principal Advisory Coaching Panel

Session-level note for coaching-style panel design.

## Working rules
- Treat a long-term principal advisory panel as *persistent coaching mode*, not a one-shot verdict.
- Start by identifying the actual coaching need; do not force the panel into a principal-only frame if the user is really deciding, planning, reflecting, or unblocking.
- Keep the panel small by default. A 5-seat core panel is usually enough:
  - strategy
  - operations
  - finance
  - people / leadership
  - values / philosophy
- Run advisors consecutively, never concurrently.
- Synthesize into one clean recommendation for the user; do not dump raw advisor notes.
- Use public-human mirrors for professional lanes when a credible public fit exists.
- Use philosophies, frameworks, or operating doctrines for personal / identity / values lanes.
- If the user changes topics, reset the panel cleanly to the new topic.
- If the user wants to continue later, preserve the thread state and keep the session warm.

## Output preference
- Give the user the next useful step, then the smallest useful question if more context is truly needed.
- If the user is already ready to act, respond with the recommendation and the immediate next move.
