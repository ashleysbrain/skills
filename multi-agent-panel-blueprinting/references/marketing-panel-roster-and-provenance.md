# Marketing panel roster and provenance

Session-derived rule for marketing advisory panels:

- Use the **actual marketing roster** from the project docs, not product personas or approximate equivalents.
- For the DS/Hydra-style marketing sync, the roster found in source docs was:
  - **Quill** — content architect / copywriting / publishing pipeline
  - **Aura** — brand / UX / brand alignment
  - **Muse** — creative / campaign strategy / channel strategy
  - **Pixel** — visual / design intelligence / landing-page and asset direction
- When presenting recommendations, keep each advisor separated and labeled:
  - advisor name
  - role / lane
  - recommendation
  - why it matters
- Do **not** mush the four voices into one synthetic summary if the user explicitly asked for separate advisor outputs.
- If the roster is unclear, search the repo/docs for the canonical attendee list before answering.
- If a prior answer mapped the panel to the wrong personas, correct the mapping explicitly and apologize briefly.
- In marketing/positioning work, the panel is usually about content clarity, brand consistency, campaign narrative, and visuals; avoid borrowing unrelated product personas unless the source docs actually say they own the marketing lane.
