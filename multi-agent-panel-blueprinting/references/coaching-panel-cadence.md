# Coaching Panel Cadence

Use this reference when designing a coaching-style panel for a user.

## Core pattern
1. Identify the user's actual coaching need first.
2. Select only advisors whose lanes match that need.
3. Run advisors one at a time, consecutively, not concurrently.
4. Keep each advisor inside its lane.
5. If the need falls outside the existing panel, recommend a new advisor category.
6. After all individual reviews are complete, synthesize one combined result for the user.

## Important guardrails
- Do not assume the panel is principal-only.
- The coaching need may be leadership, finance, marketing, parenting, health, relationships, operations, research, or something else entirely.
- If the user need changes, the panel can change with it.
- The final user-facing answer should be the synthesis, not a dump of every individual advisor note.

## Good signals that a new advisor is needed
- The current advisors cannot answer a question without leaving their wheelhouse.
- The user changes from one coaching category to another.
- The user explicitly asks for a new kind of expertise.
- The panel starts forcing a role instead of following the actual need.
