# Architecture Overview Reference

## The Resonance + Mastermind Model

### Resonance (How the Engine Coaches)
- **Physics Principle**: When driving force matches system's natural frequency, energy transfer is maximized
- **Coaching Application**: Engine computes user's resonant frequencies from 8D scores, drives coaching interventions at those frequencies
- **Key Rule**: Coaching never pushes against user - amplifies existing motion
- **Impedance Matching**: Match coaching amplitude to user's energy state (high energy → high-drive, low energy → gentle coaching)
- **Coupled Wave Propagation**: Coaching in one dimension propagates to others (Physical → Emotional: 0.7, Physical → Intellectual: 0.5)
- **Phase Detection**: Where is user in their cycle? (Depression, Hypomanic, Stable, Transition phases)

### Mastermind (How the Advisory Panel Thinks)
- **Napoleon Hill's Principle**: Coordination of knowledge and effort toward definite purpose in spirit of harmony
- **Coaching Application**: Multiple advisory seats collaborating produce insights no single advisor could generate alone
- **Requirements**: Definite purpose, harmony (advisors in phase), coordination (engine orchestrates), diversity (different perspectives)
- **Third Mind Generation**: Engine synthesizes inputs to produce emergent insights from collaboration
- **Phase Alignment Protocol**: Before each session, check if advisors are "in phase"; if aligned, mastermind activates

### System Overview
- **Layer 1**: Health Data Platform
- **Layer 2**: Intelligence Engines (the specialist engine + the specialist engine)
- **Layer 3**: 8D Scoring Engine (PIML)
- **Data Flow**: User Input → Mode Router → Resonance Core → (Mastermind Core if Advisory Mode) → Coaching Core → Personality Engine → Response Delivery → Feedback Loop
