# Divinity Science Naming Convention

Session-derived naming rule for the Divinity Science agent family:

- Use `DS` as the outward-facing prefix on related agent names so the family reads as a coherent market-facing brand.
- Keep the lead coach stable as `the specialist engine` unless the user explicitly changes it.
- Prefer consistent prefixed variants over mixed prefixed/unprefixed naming within the same roster.
- Apply this as a naming constraint for persona/agent architecture work, not as a generic naming rule for unrelated brands.

This file exists so future sessions can recover the naming convention quickly without re-deriving it from chat history.
