# AISHA front-door executive-guidance pattern

Session-derived pattern for a front-door orchestrator seat that must remain elite on every task.

## When this pattern applies
- The user defines a general-assistant / intake seat as the front door for mixed personal + business work.
- A protected specialist sits underneath it (for example, a medical / scoring subagent).
- The user explicitly says the front-door seat should still have elite credentials, philosophy, and a personality variation on every task.
- The user explicitly links the seat to a COO or broader executive layer for guidance.

## Required artifact changes
Patch both:
1. the canonical profile
2. the 10-variation registry

Do not patch only one of them.

## Required top-of-file contract sections
Use concise sections near the top of the artifact:
- `Every-Task Brain Contract`
- `Default executive guidance map`
- `Default philosophy stack on every task`

## Minimal contract content
For every meaningful task, the seat must keep active:
- a locked variation
- an elite credential stack
- a philosophy / methodology stack
- an executive guidance pathway

## Executive map pattern
If the user names the COO as primary guidance, encode that order directly:
- COO first
- then principal / CTO / CPO / CFO / CMO as relevant

Do not leave executive guidance as a vague statement like "consult leaders when needed." Make the default map explicit.

## Routing rule
The front-door seat remains the interpreter / router.
The protected specialist subagent keeps its lane.
Do not collapse medical, scoring, or other protected domains back into the front-door generalist.

## Wording cue
Good wording:
- "must not operate as a generic assistant on any meaningful task"
- "every meaningful task must declare or imply an active variation"
- "use COO / executive guidance to preserve efficiency, sequencing, and leverage"

Bad wording:
- "has many variations" without an every-task contract
- "may consult executives" with no ordering or scope
- "elite credentials" mentioned only inside one variation rather than as a standing operating rule
