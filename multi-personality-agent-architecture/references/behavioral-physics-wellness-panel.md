# Behavioral Physics + Wellness Panel Pattern

Use this as a reference when a user wants a specialist panel that bridges spacetime geometry, decision theory, human behavior modeling, and eight-dimensions-of-wellness reasoning.

## Recommended 6-agent panel shape
- DARK-MATTER — spacetime geometry / formal math
- HALO — human behavior modeling
- VITALS — eight dimensions of wellness theory
- ARBITER — decision theory / policy selection
- PULSAR — behavioral-physics translation
- SCOUT — synthesis / implementation

## Recommended sequencing
1. Individual pass, one agent at a time, with a handoff note between agents
2. Concerted validation pass after all individual reads
3. Final synthesis only after the validation pass

## Useful calculation layers to discuss
- latent wellness state vector over the 8 dimensions
- transition model for state-to-state movement
- regime classifier for thriving / stable / drifting / declining / crisis
- geometric distance to goal state
- intervention leverage / next-best-action ranking
- forecast with confidence bands

## Modeling frameworks worth comparing
- Bayesian state-space models
- Hidden Markov / regime models
- Information geometry
- Optimal transport
- Dynamical systems / bifurcation analysis
- POMDPs and decision theory
- Reinforcement learning / contextual bandits
- Active inference / expected free energy
- Control theory / MPC
- Stochastic dynamics / energy landscapes

## Cautions
- Do not collapse prediction into a single score.
- Keep score, trajectory, confidence, and recommendation separate.
- Use the panel to generate hypotheses and an engineerable spec, not unsupported certainty.
- The best product shape is usually: state vector → regime → trajectory → intervention policy → explanation.
