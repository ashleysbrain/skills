# Public Figure Mirroring Notes

## When this pattern applies
Use when the user wants an agent to mirror a *public human figure* rather than a generic persona.

## Core rules
- Use *public* TWC scores for the mirrored human figure.
- Keep the mirrored agent updated with the latest public news and public information about that human.
- Treat the mirrored agent as the human's public brain/skillset profile, not as a private coaching profile.
- Give the agent a unique **DS-** prefixed creative name that describes the human.

## Naming pattern
- Prefer a descriptive name that evokes the human's public identity or role.
- Keep the `DS` prefix stable across the family.
- Avoid generic AI-brand names when a human-mirroring name is requested.

## Practical caution
- Separate public-figure mirroring from private-user scoring and private health coaching.
- Do not mix public TWC logic into the principal-only health scoring or other private person workflows.
