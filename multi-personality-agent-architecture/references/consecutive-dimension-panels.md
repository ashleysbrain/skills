# Consecutive Dimension Panels

When a task needs multiple dimension lenses, run them one at a time, not in concert.

## Rules
- One lens completes before the next begins.
- Pass a short handoff note from the prior lens to the next.
- Keep the same source material available to each lens.
- Do not fan out dimension lenses in parallel just because concurrency is available.
- Merge only after all required lens reads are complete.

## Output contract
Each lens should return:
1. Dimension read
2. Best recommendation
3. Support move
4. Watch item
5. Escalation note
