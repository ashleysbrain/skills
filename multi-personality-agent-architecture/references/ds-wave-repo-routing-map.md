# the specialist engine Routing Map

## Purpose
This file captures the repo split and handoff order for the specialist engine advisory work.

## Repos

### principal advisory panel
- **Repo:** `ds-wave-ceo-advisory-panel-private`
- **Use for:** long-horizon company judgment, strategy, operations, values, capital, and risk

### Product advisory panel
- **Repo:** `ds-wave-product-advisory-panel-private`
- **Use for:** product direction, discovery, behavior, evidence, and positioning
- **Special note:** if the marketing board has already reviewed the work, use that review as upstream context for product next steps and product questions

### Marketing advisory panel
- **Repo:** `ds-wave-marketing-advisory-panel-private`
- **Use for:** audience, messaging, content, distribution, brand, and launch

### Elite conclave
- **Repo:** `ds-wave-elite-conclave-private`
- **Use for:** public figure mirrors, audience signal, and media/reach lens

## Default handoff order
1. principal for the strategic frame
2. Product for product-definition or evidence work
3. Marketing for market-facing, positioning, or launch work
4. Elite only when a public mirror or external audience signal adds value

## Operating rules
- Keep each repo private and scoped to its own lane.
- Keep advisor outputs separate unless the user explicitly asks for synthesis.
- Ask one useful question at a time in coaching mode.
- Treat cross-repo handoffs as deliberate artifacts, not chat-only memory.
