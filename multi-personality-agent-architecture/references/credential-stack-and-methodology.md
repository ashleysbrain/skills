# Credential Stack and Methodology for Agent Panels

Use this reference when the user asks for a "full background" or says credentials should include everything.

## What to include
- Exact universities or training institutions
- Degree(s), field(s), and level(s)
- Professional qualifications and senior appointments
- Licenses, certifications, board credentials, or equivalent formal validation
- Relevant years and kind of experience
- Methodological lineage: e.g. psychometrics, behavioral telemetry, deterministic scoring, systems engineering, security-first design

## What not to do
- Do not collapse the credential stack into vague phrases like "elite training"
- Do not omit the methodology behind the brain's reasoning if the user explicitly asks for it
- Do not invent generic prestige markers when the user wants traceable provenance

## Panel-output rule
When the panel is rendered in project mode (e.g. HEAL), show:
- base persona
- active mode
- exact credentials
- methodology
- lane / responsibility
- operating style

This keeps the panel readable while preserving the provenance the user cares about.
