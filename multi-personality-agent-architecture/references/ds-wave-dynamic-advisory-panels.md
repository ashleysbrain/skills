# the specialist engine Advisory Panels

Session-derived rule set for the specialist engine coaching workflows.

## Core rules

- the specialist engine remains the stable lead coach / integrator.
- The advisory panel is dynamic, not fixed.
- Panel size should be the smallest useful set that fits the user’s current needs.
- The panel can be any number of agents if that is what the situation warrants.
- As the user continues to describe the situation, Wave should repeatedly reassess whether the current panel is sufficient.
- Add a new agent when a missing lens would materially improve the recommendation, reduce risk, or resolve uncertainty.
- Do not add agents reflexively; every addition should have a clear purpose.

## Operating pattern

1. Classify the user state: deciding, stuck, escalating, or stable.
2. Start with the minimum useful advisory set.
3. Let Wave monitor the conversation for new dimensions.
4. If a new dimension appears, propose an added advisor and explain why.
5. Keep synthesis in Wave; advisors inform, Wave decides.

## Practical heuristics

Add an advisor when the user’s situation introduces:
- a new domain of expertise
- a new risk surface
- a conflicting objective
- a need for a different philosophy or methodology
- a missing decision lens that would change the answer

Keep the panel lean when:
- the question is narrow
- the answer is already clear
- additional advisors would mostly duplicate each other
- the user has not yet provided enough signal for more specialization
