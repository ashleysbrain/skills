# the specialist engine Panel Selection Spec

Use this reference when the user asks for a long-term principal coach, a coaching lead, or an advisor panel for the specialist engine.

## Default panel shape
- **Lead coach:** principal mentor / integrator
- **Core advisors:**
  - Industry-matched principal
  - Marketing principal
  - Finance / funding principal
  - Talent principal
  - Mission / philosophy alignment principal
- **Conditional advisor:** Growth principal
- **Health-only advisor:** Health / medical principal

## Selection order
1. Identify whether the request is **coaching** or **execution**.
2. Treat the request as **deciding** if the user is choosing between strategic paths.
3. Start with the **smallest useful advisor set**.
4. Keep the **principal mentor / integrator** stable across sessions unless the user asks to replace them.
5. Add specialists only when they materially change the decision.

## Advisor prioritization rules
- Choose **industry-matched principal** when market or sector fit matters.
- Choose **Marketing principal** when the issue is positioning, launch, proof, content, or distribution.
- Choose **Finance / funding principal** when the issue is pricing, runway, monetization, or capital strategy.
- Choose **Talent principal** when the issue is hiring, delegation, roster design, or org structure.
- Choose **Mission / philosophy alignment principal** when the issue is identity, values, firewalls, or long-term direction.
- Add **Growth principal** when the issue is scale, compounding acquisition, funnels, retention, or expansion.
- Use **Health / medical principal** only for actual health/medical decision lanes; do not add it by default.

## Advisor execution format
Each advisor should answer in the same compact shape:
- What this lens sees
- Strongest recommendation
- What to carry forward
- Unresolved risk / watch item
- Whether human review is needed

## Synthesis rule
- The lead coach synthesizes all advisor notes into one recommendation.
- Do not hand the user a chorus of disconnected opinions.
- Do not run broad panels in parallel when the goal is synthesis.
- Prefer one advisor at a time, then merge.
