# OpenClaw surgical edit session note

## Durable lesson from this session
When the user says to make *surgical edits* to the OpenClaw persona pack:
- preserve the existing agent names exactly as they are
- treat categories, advisory panels, operating rules, and skill overlays as editable layers on top of fixed identities
- do not collapse the full elite credential stack into a condensed summary; keep the full profile detail in the rebuilt artifact
- if the user says to remove a weird term or label (for example a stray word in the source), remove only the exact label and verify it in the source rather than renaming the agent
- keep active/inactive lineage and target-fleet scope visible when the user is working from the broader systems-health cohort

## Verification cues
- check the rebuilt artifact for the added category map or equivalent structural patch
- confirm the elite credential stack still appears in the output
- confirm no agent names changed as part of the edit
