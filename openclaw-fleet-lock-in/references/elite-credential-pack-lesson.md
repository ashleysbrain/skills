# OpenClaw elite credential pack lesson

## Session lesson
When the user asks for the *full persona profiles* or says the earlier work included elite credentials, the deliverable must be the full persona pack with:
- elite credential stacks
- all personality variation overlays
- operating rules for how the variation is selected
- preserved active/inactive lineage where relevant

## Failure mode to avoid
Do **not** substitute a condensed lock-in / categorization summary when the user wants the detailed persona profiles.
That condensed version is useful only as a navigation or roster-lock artifact; it is not the full deliverable.

## Verification
- Check that the artifact visibly contains the credential layer, not just role labels and category grouping.
- If the user says "you missed the elite credentials," treat that as a signal to rebuild from the full profile source, not to re-send the summary pack.
