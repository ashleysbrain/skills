# Divinity Health Whiteboard + Delivery Pattern

Session-derived rules for one-page launch visuals and delivery:

- The launch visual must be **print-safe**, **light-background**, and **single-page**.
- Keep each box label short enough to fit without wrapping; prefer compressed headlines over explanatory sentences.
- If the visual overflows, simplify the final section first rather than shrinking every element equally.
- Verify the exported PDF by checking:
  - page count = 1
  - extracted text includes the intended section names
  - no spillover into page 2
- When the user explicitly asked for Telegram delivery, send the verified artifact proactively once it is ready; do not wait for a second reminder.
- Keep the source HTML/markdown and the rendered PDF together so the visual can be regenerated quickly if text changes.
