# Strategic Intelligence Brief Template

Session-derived from a robotics/AI industry brief (July 2026). Use as scaffolding for any multi-question strategic research brief the user requests.

## Key constraints learned

1. **Word count is a hard ceiling** — user said "under 1500 words" and meant it. Track word count during writing. Use tables to compress information density.
2. **Dense and actionable** — every line carries a name, number, or date. No filler, no restating the question, no "let me explain the background."
3. **Vocabulary constraints apply** — if the user says "no biological terms," replace ALL organism/neural/cognitive language with distributed-systems analogs. This is common for investor-facing or external DS documents.

## Structure that worked

```
# STRATEGIC INTELLIGENCE BRIEF: [TOPIC]
**Prepared:** [DATE] | **Classification:** Internal Strategy

## 1. [FIRST SUB-QUESTION HEADING]
### Subsection with framework comparison tables
### Key voices table (Name | Position | Quote/Summary)
### Leading indicators (bullet list)
**Bottom line:** one-paragraph synthesis

## 2. [POSITIONING / COMPETITIVE]
### Differentiator table (Competitor | Architecture | Our Advantage)
### Unique moat paragraph
### Positioning timeline (NOW vs FUTURE)

## 3. [HIRING / RESOURCE ALLOCATION]
### Must-have core (table: Role | Why)
### High-value adjacent (table)
### Emerging/future bets (table)

## 4. [MARKET STRUCTURE]
### Funding landscape table (Company | Round | Valuation | Date)
### Market size projections (bullet list with source attribution)
### Where money is flowing (Hot/Warm/Greenfield categorization)

---
*Sources: [list all sources accessed]*
```

## Research fallback ladder (when search engines are blocked)

When Google, Bing, and DDG all CAPTCHA-block from server IPs:
1. `browser_navigate` to Wikipedia articles — most reliable for company data, technology definitions
2. Direct site navigation to known URLs (crunchbase, company press pages, Goldman Sachs insights)
3. arXiv direct access for academic papers
4. Supplement with training knowledge, flag freshness limitations transparently

## Density techniques

- Tables for any 3+ item comparison (saves 60-70% word count vs paragraphs)
- `|` pipe tables for side-by-side competitor analysis
- Bullet lists for projections/indicators
- Bold inline for key numbers/names ($39B, 107+ engines, 2025)
- No introductory paragraphs — start with substance immediately
