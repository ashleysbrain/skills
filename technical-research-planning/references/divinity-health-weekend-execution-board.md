# Divinity Health Weekend Execution Board Pattern

## When to use
Use this pattern when a launch weekend starts late in the day and the team must ship both marketing and product momentum without spreading into vague planning.

## Core operating rule
- **Marketing leads the weekend. Product supplies proof.**
- Build just enough product to create visible evidence.
- Turn that evidence into launch copy the same day.
- Use outreach, launch posts, and partner messages to learn what to improve next.

## Compressed schedule shape
### Saturday afternoon
1. principal lock
   - audience
   - one-line promise
   - CTA
   - open-core boundary
   - parent-methodology vs commercial-product distinction
2. Product proof sprint
   - smallest visible flow
   - screenshots
   - short demo path
   - before/after or state/next-step proof
3. Messaging build
   - homepage hero
   - headline options
   - founder story
   - FAQ
   - waitlist CTA
4. Asset packaging
   - launch post
   - proof post
   - educational post
   - email
   - Telegram message
   - partner outreach message
5. Publish-ready polish
   - clarity
   - consistency
   - brand split
   - proof visibility
   - CTA sharpness
6. Outreach prep
   - warm contacts
   - beta users
   - partners
   - community amplifiers

### Sunday
1. Product refinement
   - tighten onboarding
   - sharpen first impression
   - improve one retention mechanic
2. Launch batch
   - publish posts
   - send email
   - send Telegram message
3. Outreach sprint
   - targeted DMs
   - beta asks
   - feedback asks
   - partner asks
4. Review and triage
   - reactions
   - replies
   - signups
   - friction points
   - next-week priorities

## Artifact format that worked well
For weekend launch boards, use a simple checklist with:
- owner
- support
- task
- output
- done when

This format kept the plan readable and easy to execute live.

## PDF export and verification lesson
When turning the weekend plan into a PDF:
- write the checklist in clean markdown first
- generate the PDF from source
- verify extracted text for the title and the key section headers before delivery
- if the output looks visually fine but the extracted text is messy, regenerate until the PDF is clean enough to search and quote

## Why it matters
This pattern helps the team launch fast without sacrificing product proof or clarity in the market story.
