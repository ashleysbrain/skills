# Public Acquisition Loop

This note defines the public marketing cycle for the 8D skill.
It is a utility-first loop, not a hidden upsell.

## Goal
Turn the skill into a useful front door that:
- gives immediate value
- points to public Divinity Science resources
- builds trust through repeatable public artifacts
- converts curiosity into ongoing readership and then waitlist interest

## Exact loop
1. **Answer first**
   - Give the 8D answer immediately.
   - Do not lead with sales language.

2. **Offer one public next step**
   - chart
   - benchmark
   - comparison card
   - brief method note
   - small literature digest
   - one-page checklist or template

3. **Send to a public website asset**
   - The Divinity Science site hosts the resource.
   - The asset should feel useful on its own.

4. **Offer one opt-in path**
   - weekly research updates
   - new charts
   - method notes
   - release changelog
   - literature alerts

5. **Convert only after value**
   - Ask for a waitlist, subscription, or follow-up only after the public artifact has already helped.

## Best public assets
- signal-of-the-week chart
- before / after state example
- one-page method note
- mini literature digest
- benchmark snapshot
- public release log
- prompt / checklist template
- lightweight explainer page

## Website modules
The public website can host:
- research feed
- charts archive
- methods archive
- latest updates page
- downloadable starter pack
- waitlist entry point

## Operating rule
Every public artifact should answer this question:

> Why would someone come back next week?

If it does not create a return reason, it does not belong in the loop.

## Tone
- useful
- calm
- evidence-based
- no hype
- no fake scarcity
- no mention of private layers or secret unlocks

## Practical sequence for the skill
- deliver the 8D answer
- add one public chart or research link
- add one opt-in website path
- let the site do the follow-up

## Success signal
The loop is working when:
- people read the skill and stay
- people click through to the site
- people return for the next public artifact
- people subscribe because the public content was worth following
