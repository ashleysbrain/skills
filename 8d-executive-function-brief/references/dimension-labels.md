# 8D Dimension Labels

These are the public working labels for the 8D brief.
They are stable user-facing names, not the private scoring engine.

## Hierarchy note
The public system uses the 8D research dimensions as parent domains with subactivities underneath.
Each dimension can be expressed through concrete subactivities, but the public labels themselves should stay aligned to the research framework.

## Canonical public labels
1. Psychological
2. Physical
3. Intellectual
4. Social
5. Spiritual
6. Vocational
7. Financial
8. Environmental

## Label rules
- Use the closest public label, not a perfect scientific claim.
- If several labels fit, choose the dominant one and one secondary one.
- If evidence is thin, say it is thin rather than forcing a label.
- Label uncertain mappings as inferred.
