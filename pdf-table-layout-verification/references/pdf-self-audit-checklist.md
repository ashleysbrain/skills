# PDF Self-Audit Checklist

Use this before sending any PDF to the user.

## Print-first defaults
- Prefer a light or white background unless the user explicitly wants a dark presentation style.
- Use dark, high-contrast text.
- Avoid decorative fills behind long text blocks.

## Layout checks
- Confirm content stays inside the page margins on every page.
- Check that nothing is clipped at the left/right edges.
- Verify headers, footers, and page numbers are visible.
- Check the widest page, not just the cover.
- If the PDF is intended for print, make sure any full-page art or panels still leave safe margins.

## Readability checks
- Ensure headings are readable at print size.
- Avoid tiny text, dense blocks, and crowding.
- Keep line lengths reasonable.
- Verify bullets and numbered lists do not run off the page.

## Delivery checks
- Confirm the final artifact is the exact file you intend to send.
- Verify file size and page count are plausible.
- If sending via Telegram, use an absolute `MEDIA:` path.

## Rule of thumb
If you would hesitate to print it yourself, do one more audit pass before delivery.
