# Combined algorithm master panel review lessons (2026-06-02)

Use this note when rebuilding a combined algorithm deck that must present the original base algorithm, the family stack, and a panel-ready addendum with visible repair work.

## Lessons captured
- Front-load the original/base algorithm as a distinct early section so reviewers can see the anchor immediately.
- Keep the family identifier stable even if the section heading is renamed for readability.
- If a support family contains multiple inputs that are conceptually distinct, split them into separate cards/sub-calculations instead of flattening them.
- Put a status label on every algorithm/card, not just the summary banner.
- If a header badge is hard to read, fix the contrast in the rendered artifact and re-check the PDF text layer.
- When adding repair formulas, give each one its own visible card with provenance and status so panel reviewers can tell what is live, spec, or research.
- For dense PDF pages, verify both the visual render and text extraction; a heading can exist visually but still be awkward to search if line breaks or small badges fragment the text layer.
- For multi-point fields such as time, distance, or where/location, expose intermediate points/calculations instead of collapsing them into one scalar.

## Verification note
The combined artifact should be rebuilt after edits and checked with both text extraction and a block-level readout of the dense pages so the newly added headings remain searchable and readable.
