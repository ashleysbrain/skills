# Biological-to-Technical Abstraction Framework

## Purpose

When releasing internal agent methodology as public open-source skills, the internal biological inspiration must be abstracted into clean engineering terminology. This framework maps private internal names to public skill names and concepts, ensuring the biological blueprint stays private while the methodology reaches the public.

## Discretion Rules

1. Never mention body parts, organs, tissues, neurons, or anatomy in any public skill. Use engineering terms: "components," "subsystems," "service mesh," "processing modes."
2. The 6 process-flow categories become "operational modes" — neuromodulatory = "cognitive mode selection," oscillatory = "synchronization," etc.
3. Scientist names stay internal. Public skills use role names: "The Router," "The Verifier," "The Producer."
4. The biological inspiration documents (BRAND-DNA, anatomy specs, ecs.py) never leave private repos.
5. "Powered by Divinity Science" is the badge — it signals methodology without revealing the system.

## Usage-First Release Ordering

Foundation skills first, polish skills last. A user installing in order never hits a wall.

### Phase 1: Foundation (Week 1)
1. Task Router Protocol — classifies domain
2. Expert Dispatch Framework — right specialist for single-domain
3. Mastermind Collaboration Protocol — right pattern for multi-domain
4. Session Continuity Engine — survives crashes
5. Output Verification Engine — checked before delivery

### Phase 2: Enhancement (Week 2)
6. Agent Persona Calibration — tune HOW specialist works
7. Processing Mode Switch — adapt approach to task type
8. Physics-Informed Project Management — manage overall flow

### Phase 3: Output Polish (Week 3)
9. Humanizer — strip machine patterns
10. Review Panels — multi-perspective decisions
11. Golden-Ratio Design Pipeline — beautiful creative output

### Phase 4: Advanced (Week 4+)
12. Brand Consistency Engine
13. Service Mesh Topology
14. Five-Layer Agent Architecture

## Naming Convention

Use `ds-` prefix for brand consistency without revealing what "DS" stands for internally. Users see it as a methodology brand. Examples: `ds-expert-dispatch`, `ds-session-continuity`, `ds-golden-ratio-design`.

## Open-Core Boundary

**Public (MIT licensed):**
- The workflow protocol
- Template files and examples
- Verification scripts
- Documentation
- Generic profiles/templates

**Private (the moat, never published):**
- Calibrated scoring weights
- Full specialist profile library
- The biological engine implementations
- The ECS registry
- Brand DNA specifics
- The full organism (the operator agent)
