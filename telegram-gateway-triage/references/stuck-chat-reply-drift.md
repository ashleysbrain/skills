# Stuck Chat / Reply Drift Notes

Session pattern:
- User reported Telegram was "stuck and not working correctly."
- The assistant then drifted into unrelated repo/status language instead of staying on the Telegram issue.

Recovery pattern:
1. Acknowledge the mismatch briefly.
2. Re-anchor on the latest Telegram complaint.
3. Separate delivery/routing problems from content/reasoning drift.
4. Ask for the last successful Telegram message or the exact symptom if a concrete next step is needed.

Anti-pattern:
- Do not pivot into unrelated work, side projects, or file/repo updates when the user is reporting a Telegram delivery problem.
- Do not defend the stale interpretation once the user has corrected it.
