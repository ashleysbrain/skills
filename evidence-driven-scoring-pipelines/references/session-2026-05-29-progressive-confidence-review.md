# Progressive Confidence Review Pattern

Session note for evidence-driven scoring specs that evolve over a wake cycle.

## Lessons

- Define the day by the user's *sleep-wake cycle* when the domain is biologically linked to sleep.
- The score should represent the current best belief; the confidence should increase as additional corroborating evidence arrives during the wake session.
- Confidence growth should come from breadth, recency, reliability, and corroboration — not from a hidden reward loop.
- When reviewer feedback is annotated or numbered, answer point-by-point and convert each note into an explicit product decision.
- If a reviewer asks about goals, operating process, data sources, or scientific grounding, add a dedicated response section or appendix in the artifact so the decisions are easy to audit.
- Keep the response actionable: each comment should map to a concrete spec change, terminology update, or appendix entry.
