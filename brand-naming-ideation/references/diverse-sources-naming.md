# Diverse-source naming for subsidiaries / real companies (session 2026-08-11)

## Trigger
User asks for company/subsidiary name candidates and explicitly rejects a previous
batch for being too siloed in one root family (e.g. Greek/Latin philosophy). They
want DIVERSE SOURCES and feel that is ESTABLISHED and TRUSTWORTHY.

## What was asked for
15 diverse, creative company names for a Divinity Science subsidiary, each with an
available domain. Sources must span: nature/biology, engineering/architecture,
music/acoustics, chemistry/physics, cartography/exploration, poetry/literature,
craft/trade, light/optics. NOT Greek/Latin philosophy. NOT generic tech words
(FORGE, CIPHER, BRIDGE, VAULT). Feel like Stripe, Palantir, Anduril, Anthropic.

## The diverse-source pool (what actually has available domains)

### Tier 1 — single real dictionary words with domains available
Rare/specialized nouns from craft, biology, chemistry, architecture. Common single
words (nacre, gimbal, cartouche, kiln, marrow, albedo, azimuth, sextant) are 100%
squatted across .com/.io/.ai — registered in the 1990s. The words that still had
availability were the MORE OBSCURE real words:

| Name       | Source                  | Available |
|------------|-------------------------|-----------|
| Osteons    | biology (bone units)    | .com .io .ai |
| Azeotrope  | chemistry               | .io .ai |
| Voussoir   | architecture            | .ai |
| Distaff    | craft (spinning)        | .io .ai |
| Nacreous   | optics/nature           | .io .ai |
| Overtonal  | music                   | .io .ai |
| Plintha    | architecture            | .io .ai |

### Tier 2 — coined compounds (brandable, like Stripe/Vercel)
Two real craft/nature words joined. These are the MOST LIKELY to have .com available
because they're coined combinations, not dictionary words:

| Name        | Source                       | Available |
|-------------|------------------------------|-----------|
| Bindweft    | craft (weaving)              | .com .io .ai |
| Ropestrand  | craft (cordage)              | .com .io .ai |
| Codexwork   | literature + craft           | .io .ai |
| Glyphwork   | cartography + craft          | .io .ai |
| Cairnstone  | exploration                  | .ai |
| Yewtree     | nature                       | .io .ai |
| Loomsong    | craft + music                | .io .ai |
| Kilnsong    | craft + acoustics            | .io .ai |

## Key insight: the availability gradient
1. **Common single dictionary words** (kiln, marrow, gimbal) → 100% squatted. Never surface these as primary candidates for real registration.
2. **Obscure single real words** (osteons, azeotrope, voussoir) → often available on .io/.ai, occasionally .com.
3. **Coined two-word compounds** (bindweft, ropesand) → most likely to have .com available. This is the Stripe/Vercel/Anthropic pattern — recognizable real-word components, but the combination is unique enough to register.

So when domains matter: **lead with coined compounds, not dictionary words.**

## Source categories that produce good "established" names
- **Craft/trade vocabulary**: weft, warp, shuttle, bobbin, distaff, loom, kiln, anvil, forge-smithing terms
- **Architecture/structural**: voussoir, corbel, purlin, trunnion, pintle, plinth, cantilever, tenon/mortise
- **Navigation/cartography**: azimuth, rhumb, traverse, sextant, cartouche, cairn, compass terms
- **Biology (structural)**: osteons, cambium, meristem, thallus, mycelia — the structural/functional words, not species names
- **Chemistry/materials**: azeotrope, allotrope, fullerene, valence, sublimate, valency terms
- **Music/acoustics**: overtone, ostinato, fermata, sonance, resonance terms
- **Optics/light**: albedo, scintilla, prismatic, lumens, refraction terms

## What NOT to do
- Do NOT reach for Greek/Latin philosophy roots (episteme, aletheia, gnosis, numen, telos) when the user has asked for diverse sources.
- Do NOT surface common single English dictionary words as primary candidates when domain registration is the goal — they are squatted.
- Do NOT mix naming styles (some coined, some dictionary, some philosophy) in one batch — pick one register per batch.
- Do NOT use generic tech words (FORGE, CIPHER, BRIDGE, VAULT, SHIELD, NEXUS) — explicitly rejected.

## Response format that worked
- Table: Name | Source | .com | .io | .ai status
- Followed by a "diversity of sources covered" breakdown
- Flag the strongest picks (single-word vs brandable compound)
- Max ~500 words for a 15-name batch
