# Agent/System Naming Note

Session-derived naming rule for 8D AI products:

- Keep the **agent name** and **system name** separate when the user asks for both.
- Example pattern:
  - Agent: the specialist engine
  - System: 8D Heal AI
  - Agent: the specialist engine
  - System: 8D Coaching
- Use the agent name for the persona/operator that manages the workflow.
- Use the system name for the engine/platform/product layer.
- If the user wants an 8D-related family, keep the `8D` marker in the system name unless explicitly requested on the agent name.
- Prefer crisp, role-revealing names over ambiguous umbrella labels when the architecture has multiple layers.
