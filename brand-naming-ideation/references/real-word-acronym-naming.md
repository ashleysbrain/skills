# Real-Word Acronym Naming Pattern (2026-08-08, updated 2026-08-11)

## THE PATTERN

When naming a DS PRODUCT or CATEGORY (not an engine, agent, or company), the user prefers
ACRONYMS FROM REAL DESCRIPTIVE WORDS where the acronym spells a real word
related to the concept.

**Accepted:** the OS = Modular Open System for AI Interconnectivity and Composition
- Each tile in a mosaic is a complete piece on its own (a device, a model, an agent)
- Composed together they form the full picture
- User accepted immediately, no iterations needed

**Also well-received candidates:**
- CORAL = Composable Owned Resilient Adaptive Layered
- SCION = Sovereign Composable Interconnected OS Network
- LOOM = Layered Open OS for Modular composition
- SPINE = Sovereign Personal Interconnected Native Environment

## WHAT WAS REJECTED

Coined neologisms with Latinate suffixes:
- Holonos, Kompoza, Composon, Weavos, Stakos, Holoos, Modos, Omnios
- User said: "those are terrible AI-generated names"

These followed the Kubernetes/Android naming tradition (Greek roots + evocative
suffix), but the user saw them as AI-generated. The lesson: for DS PRODUCTS,
the user does NOT want coined words. They want real words assembled into acronyms.

## COMPANY NAMES FOLLOW A DIFFERENT PATTERN (learned 2026-08-11)

The acronym pattern does NOT apply to company names. User explicitly said:
"The real-world acronym pattern does not need to be followed on this task —
that is not a preferred item for the name of a company."

Company names should feel established and trustworthy like Palantir, Anduril,
Anthropic, Stripe, Twilio, Vercel. Real words or coined derivatives with
historical, scientific, or natural roots. NOT forced acronyms.

### Diverse sources required
Do NOT silo into one source. The user rejected three batches of Greek/Latin
philosophy names ("this is incredibly siloed with Greek names — be more
creative than this"). Pull from ALL of these:
- Nature and biology
- Engineering and architecture
- Music and acoustics
- Chemistry and physics
- Cartography and exploration
- Poetry and literature
- Craft and trade
- Light and optics

### Domain availability
Raw dictionary words (Greek roots, Latin roots, common English words) are
almost always domain-squatted on .com. Coined derivatives from those roots
(the Palantir/Anduril approach) are more likely to have available domains.
ALWAYS check domain availability via whois as part of the naming pass, not as
a separate follow-up step. Use authoritative whois servers:
- .com: whois.verisign-grs.com
- .io: whois.nic.io
- .ai: whois.nic.ai
Default whois may misroute to IANA and return false "TAKEN" results.

### Volume
When the user says "I just need a lot to choose from as nothing stands out yet.
When I know I'll know" — generate 15-20+ candidates, not 10-12. High volume
with domain checks is the right approach for company naming.

## NAMING HIERARCHY BY COMPONENT TYPE (updated 2026-08-11)

| Component Type | Naming Pattern | Example |
|---|---|---|
| Engines / Organs | Real scientist names | the specialist engine, the specialist engine |
| Products / Categories | Acronyms from real words | the OS OS |
| Processes / Pipelines | Metallurgical etymology | VERITAS, CRUCIBLE |
| Companies | Real/coined words, NOT acronyms | Palantir-style, diverse sources |

Each layer has a DIFFERENT naming convention. Do not mix them.
