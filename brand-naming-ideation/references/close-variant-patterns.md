# Close-variant naming patterns for coined brand names

Session note: the user rejected an initial batch of DS-style names and then asked for names *similar to* `the specialist engine` with meanings.

## What worked
- Stay in the same phonetic family as the seed name.
- Mutate only one or two features at a time:
  - suffix (`-inth`, `-alis`, `-ion`, `-ex`, `-vane`)
  - internal vowel shift (`quor-`, `quori-`, `quora-`)
  - ending strength (`-x`, `-l`, `-n`, `-th`)
- Keep the prefix if the user already likes it, especially `DS`.
- When asked “what they mean,” give a **coined meaning** or **brand interpretation**, not a literal etymology claim.
- If the user rejects multiple batches, assume the *brand lane* is wrong before assuming the phonetic treatment is wrong; narrow back to the explicitly requested industry/domain first.

## Example family from this session
- `the specialist engine` — intended meaning: council / collective clarity.
- `the specialist engine` — intended meaning: nexus of consensus.
- `the specialist engine` — intended meaning: central quorum / governing core.
- `the specialist engine` — intended meaning: quantum quorum / adaptive intelligence.
- `the specialist engine` — intended meaning: moving council / mobile coordination.

## Response pattern
1. Deliver 5-10 close variants.
2. Give each a one-line meaning.
3. If the user asks for more, stay in the same family before branching to a different vibe.
4. If the batch misses, reset the suffix family rather than the whole aesthetic.
