# Wave Panel Context Framing: Character Statement vs Primary Filing

## The Failure (2026-07-26)

I ran a 10-agent legal panel (5 legal + 5 adversarial) on a character statement
for a Texas family court dog possession hearing. I framed the panel context
as if the document were the primary legal filing. Every agent correctly cut
"character evidence" as inadmissible hearsay.

But the document WAS a character statement. Its entire purpose was pattern
of conduct and escalating behavior. The pregnancy claims, prior dog history,
and manipulation patterns were the POINT, not side notes to be cut.

The user corrected twice in one session:
1. "This is a character document. Some of the things you took out... they're the point."
2. "Go back through it, it needs to actually read as a character statement."

## The Fix

When dispatching legal panel agents for a CHARACTER STATEMENT, the context
field MUST include:

```
This is a CHARACTER STATEMENT (secondary document), NOT the primary filing.
Its purpose is to establish:
- Pattern of erratic and escalating behavior
- Fitness to care for the subject property/animals
- Manipulation tactics using the disputed property as leverage

Character evidence IS the point of this document. The panel should:
- Evaluate how to make character evidence ADMISSIBLE (affidavits, documentation, framing)
- NOT recommend deletion of pattern evidence
- Flag hearsay risks and recommend FIXES, not removal
```

## What stays vs what gets cut

| Document type | Keeps pattern evidence | Keeps pregnancy/fraud claims | Keeps prior history |
|---|---|---|---|
| Character statement | YES - it's the point | YES - shows manipulation pattern | YES - shows fitness |
| Primary filing | NO - hearsay risk | NO - prejudicial | NO - 404(b) vulnerability |

## How to position the two documents

The character statement ANTICIPATES character attacks from the opposing party.
Include a section like "Response to Anticipated Character Attacks" that:
- States what Respondent did NOT do (abandon, harm, neglect)
- Frames Respondent as PROTECTOR not AGGRESSOR
- Ties every character point back to the welfare of the disputed property

## Document pairing

When both documents exist:
- Primary filing = ownership evidence, legal framework, requested orders
- Character statement = pattern of conduct, escalating behavior, fitness

They are FILED TOGETHER but reviewed separately. The panel context must
specify WHICH document is being reviewed so agents apply the right standard.
