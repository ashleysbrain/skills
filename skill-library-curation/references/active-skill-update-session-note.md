# Active Skill Update Session Note

Session lesson:
- When the user explicitly asks to review the conversation and update the skill library, treat it as a curation audit with an expectation of a real durable update if any reusable lesson exists.
- Do not treat "Nothing to save" as the default just because the exchange looks short or the first problem was a transport/channel symptom.
- Compare the latest user message to the assistant's immediately prior reply before deciding what to save; the durable lesson is usually the workflow mismatch.
- If the user signals frustration or asks for active skill maintenance, prefer patching the governing umbrella skill and adding a concise reference note rather than only updating memory.
- If the user explicitly says to be ACTIVE, interpret that as permission to make a small but real umbrella update rather than leaving the library unchanged.

Practical curation cue from this session:
- The combination of "my Telegram is stuck" and a later explicit request to update the skill library means the next similar session should save the workflow lesson, not just the surface symptom.
- The exact phrase "Be ACTIVE" should be treated as a trigger to find at least one durable class-level improvement when the conversation contains a usable lesson.
