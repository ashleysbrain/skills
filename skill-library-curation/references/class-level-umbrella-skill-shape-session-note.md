# Class-level umbrella skill shape — session note

## Durable lesson
When the user explicitly asks for a skill-library review or says to be active, treat it as a curation audit and save at least one reusable lesson if the thread contains one.

## Shape requirement
- Prefer one class-level umbrella skill over many one-off skills.
- Keep session-specific details in `references/` instead of bloating `SKILL.md`.
- Use `templates/` for copyable scaffolds and `scripts/` for deterministic repeatable checks.

## Roster / agent expansion lesson
When the user asks to expand or repurpose a roster, inspect active *and* inactive/archived pools before sizing the work.
- Preserve existing agent lineage when the user says not to recreate agents.
- Revise skillsets and roles in place when possible.
- Do not assume the visible/live roster is complete.
