# Coaching-engine psychologically attuned tone — session note

## Durable lesson
When a user asks to make coaching questions "more user friendly" or "like a best-in-the-world psychologist and life coach," update the *whole coaching flow*, not just sample questions.

## What to patch together
- question examples
- question-design rules
- activation/opening flow language
- stuck-user handling
- response tone rules
- persona/voice rules

## Tone characteristics to preserve
- warm but not generic
- emotionally attuned without sounding therapeutic-cliché
- precise and gently directive
- oriented toward the user's real issue, including the felt pressure behind it
- supportive without sounding like an intake form

## Process-flow characteristics to preserve
- begin with an opening question flow, not "intake"
- identify both emotional and practical need
- ask the smallest useful question
- avoid cross-examining the user
- when the user is stuck, reduce confusion and restore agency, not just momentum

## Curation note
If this kind of feedback shows up again, patch the governing umbrella skill first, then add a compact reference note like this one instead of creating a narrow one-off skill.
