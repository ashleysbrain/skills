# Voice / workflow layer separation

Session lesson for skill curation.

When a user corrects a repo-owned coaching or advisory spec, distinguish:

- **voice layer**: the branded public-facing style or persona
- **workflow layer**: the reusable, agent-agnostic process

## Curation rule

If the user asks for the branded voice to remain distinct from the workflow, capture that as a durable skill update in the owning umbrella skill, and mirror the same phrasing across the core repo docs that define the process.

## Pitfall

Do not record this only as memory; it belongs in the governing class-level skill because it changes how future document rebuilds should be structured.
