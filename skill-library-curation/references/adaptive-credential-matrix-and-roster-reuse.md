# Adaptive Credential Matrix and Roster Reuse

Session lesson:
- When a user asks to expand an agent roster, inspect both active and inactive/archived pools, including adjacent canonical rosters when the current lane is only part of the picture.
- Preserve existing agents and revise identities in place when the user explicitly says not to recreate agents.
- Apply a role-by-role credential matrix rather than a single generic degree path: different role families need different elite stacks.
- Useful role families from this session:
  - Legal / compliance / advocacy: elite JD + bar + M&A / securities / governance / antitrust / arbitration.
  - Finance / growth / market: finance, economics, MBA, valuation, FP&A, market design, growth analytics.
  - Strategy / operations / leadership: MBA, MPA, operations research, org behavior, program management, decision science.
  - Technical / platform / security: CS, engineering, systems, reliability, cloud, DevOps, security, QA.
  - Research / evidence / review: research methods, statistics, domain science, publication depth.
  - Product / communication / UX: product management, HCI, design, communications, rhetoric, writing, user research.
  - Health / people / crisis / training: clinical grounding, counseling, HR, mediation, crisis leadership, teaching.
- If the user explicitly asks for a skill-library review or says to "be ACTIVE," make at least one durable update when any reusable lesson exists.
- If an artifact is rendered for review (PDF/HTML/deck), verify the output file directly rather than assuming the source edit was enough.
