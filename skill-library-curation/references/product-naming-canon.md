# Product Naming Canon — Divinity Science

## Canonical names
- `8D Heal AI` = the healing system
- `8D Coaching` = the coaching system
- `the specialist engine` manages `8D Heal AI`
- `the specialist engine` manages `8D Coaching`

## Curation lesson
When the user establishes a canonical product name or naming boundary, treat it as durable skill knowledge, not just memory. Capture it in the governing umbrella skill and apply it consistently across:
- docs
- runtime wrappers
- indexes/navigation pages
- agent/package names
- related aliases and references

## Practical rule
If a doc or artifact could blur two product lines, rename it so the distinction is obvious at the first glance.
