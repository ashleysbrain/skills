# Skill-Update No-Op Avoidance

## Session lesson

When the user explicitly asks for a skill-library review or says to "be ACTIVE," do not treat the request as a passive audit. If the thread contains any reusable lesson — tone correction, workflow correction, better verification habit, or recurring curation pitfall — save at least one durable update.

## What to capture

- the governing umbrella skill, if it already covers the lesson
- a concise reference note when the detail is session-specific
- a small but real workflow improvement rather than a no-op response

## What to avoid

- returning "Nothing to save" when there is a usable class-level lesson
- creating a narrow one-session skill when the lesson belongs in an umbrella
- burying the lesson only in memory when the workflow itself should change
