# Roster lineage and inactive-pool lesson

Session lesson:
- When the user asks to expand or reassign an agent fleet, check the *inactive / archived* roster as well as the active roster.
- If the user explicitly says the active the operator agent roster is not the whole picture, inspect adjacent canonical pools such as OpenClaw before proposing a new roster shape.
- Treat existing agents as lineage to be revised, not replaced, when the request says not to recreate agents.
- Preserve agent identity and update skillsets / roles / brains in place whenever possible.
- If the source roster is split across products or lanes, verify the canonical pool before drafting a new fleet shape.

Use this as a reminder to search all relevant roster pools before proposing new agents.
