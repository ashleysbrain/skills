# Advisor Taxonomy and Credential Standards

## Session lessons

- When a coaching or advisor workflow has a three-way taxonomy, keep the categories explicit:
  - general coaching advisors
  - public human-figure mirror advisors
  - narrow specialist advisors
- Do not collapse general coaching advisors and narrow specialist advisors into one vague "expert" bucket.
- General coaching advisors should be best-in-field or best-in-niche for the requested lane.
- Narrow specialist advisors should also be highly credentialed and elite within their narrow focus.
- "Highly credentialed" may include university research, academic or professional affiliations, and/or certifications.
- If the user has already established the taxonomy, preserve it across all related docs and runtime-facing profiles.
- Keep public human-figure mirror advisors separate from general coaching and specialist lanes; their rule set should stay public-source-only.
- If a documentation pass touches the taxonomy, verify the runtime-facing profile or SOUL file also uses the same category names and credential definitions.
