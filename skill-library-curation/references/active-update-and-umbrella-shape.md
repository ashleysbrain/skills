# Active Update and Umbrella Shape Notes

## Session lesson

When the user asks to review the conversation and update the skill library, do not treat that as a passive audit.

- Make at least one durable skill update if there is any reusable lesson in the thread.
- Prefer patching an existing class-level umbrella skill first.
- If the lesson is reusable but too session-specific for SKILL.md, store it under `references/` instead of creating a narrow one-off skill.
- Keep the final skill shape at the class level: trigger conditions, workflow, pitfalls, verification, and pointers to support files.
- When the user says the conversation or channel is "stuck" or not working correctly, inspect the latest user turn against the assistant's immediately prior reply before deciding what to save.
