# Telegram/channel stuck session note

Session lesson:
- When a user says the Telegram session is "stuck" or "not working correctly," first compare the latest user turn with the assistant's immediately previous reply.
- The useful durable update is usually the workflow mismatch or drift, not a transport-layer complaint.
- If the user explicitly asks for a skill-library review after that kind of exchange, save at least one small class-level improvement when any correction or reusable pattern is present.
- Keep the note concise and pair it with a governing SKILL.md rule, rather than turning the reference into a transcript mirror.
