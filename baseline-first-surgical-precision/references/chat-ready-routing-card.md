# Chat-Ready Routing Card Pattern

This note captures a small but useful pattern from a Telegram-delivered routing artifact.

## What worked
- Provide a **full pasteable block** for the user to copy into chat.
- Also provide a **one-line ultra-short version** for scan speed.
- Keep the copy aligned to the existing baseline; add the short form as an additive derivative, not a rewrite.
- For multi-lane advisory systems, name the lanes plainly and keep the routing rule simple:
  - start with the narrowest fit
  - escalate to the top-level lane if the question crosses boundaries
  - keep outputs separate unless synthesis is explicitly requested

## Good fit
Use this pattern when the user wants something they can paste into Telegram or another chat app immediately, especially for recurring routing or handoff instructions.
