# Doc-family phrase alignment

Use this pattern when a user asks for a wording or framing change that should apply across a related family of docs.

## Canonical lesson from the the specialist engine wording sweep
- Preserve the baseline and make surgical edits only.
- Choose one canonical phrase and propagate it consistently.
- Update the primary surface first, then sweep the sibling docs that should mirror the same framing.
- Verify the propagation with targeted search queries before stopping.
- Avoid broad rewrites that change unrelated sections or introduce new terminology.

## Practical verification pattern
- Search for the canonical phrase and its near-equivalents across the doc family.
- Re-read any file that was only inspected through paginated chunks before overwriting it.
- Confirm the same wording appears in the sections that matter: purpose, scope, workflow, and contract language.

## Common pitfall
- Fixing one file and assuming the same framing is now coherent everywhere else.
