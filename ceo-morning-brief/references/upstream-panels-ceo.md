# Upstream Advisory Panels Reference for principal Morning Brief

This document provides guidance on understanding each advisory board's lane and what kind of outputs to expect from them, to correctly identify the source of actions in the principal Morning Brief's priority stack.

## Advisory Board Lanes and Output Characteristics

### 1. Marketing Advisory Panel
**Lane**: Go-to-market strategy, positioning, audience targeting, messaging, content strategy, distribution channels, launch planning, growth tactics
**Typical Outputs**: 
- Positioning statements and category design
- Audience insights and targeting recommendations
- Messaging frameworks and content strategies
- Launch plans and go-to-market tactics
- Channel distribution recommendations
**Example Actions**: 
- "Interview five best customers to gather insights for positioning canvas" — Impact: Validates AI Wellness Coach category creation — Source: Marketing — Time Estimate: 2 hours
- "Audit one piece of public-facing copy for disease-treatment language" — Impact: Ensures compliance with health marketing guidelines — Source: Marketing — Time Estimate: 30 min

### 2. Product Advisory Panel
**Lane**: Product strategy, discovery, validation, user experience, feature prioritization, opportunity assessment, business model
**Typical Outputs**:
- Opportunity solution trees and customer insights
- Feature prioritization and scoping recommendations
- Product validation experiments and test results
- User experience flow assessments
- Business model and monetization considerations
**Example Actions**:
- "Schedule three customer interviews this week using story-based questioning" — Impact: Validates assumption about user needs across 8 dimensions — Source: Product — Time Estimate: 1.5 hours
- "Define specific, measurable outcome for user behavior change" — Impact: Shifts focus from features to outcomes — Source: Product — Time Estimate: 1 hour

### 3. CTO Advisory Board
**Lane**: Technical architecture, engineering priorities, infrastructure, technical feasibility, innovation, scalability, security, technical debt
**Typical Outputs**:
- Technical architecture recommendations and diagrams
- Engineering priority lists and sprint planning
- Feasibility assessments for proposed features
- Infrastructure and scalability recommendations
- Security and compliance considerations
**Example Actions**:
- "Reconcile engine count to one verified number" — Impact: Ensures alignment across teams on technical foundation — Source: CTO — Time Estimate: 30 min
- "Stand up GitHub Actions CI pipeline" — Impact: Provides automated regression protection for production code — Source: CTO — Time Estimate: 1 week

### 4. COO Advisory Board
**Lane**: Operations, processes, resource allocation, cross-board coordination, execution efficiency, operational metrics, workflow optimization
**Typical Outputs**:
- Operational process improvements and workflow optimizations
- Resource allocation recommendations and budget considerations
- Cross-board coordination plans and handoff specifications
- Operational metrics and KPI definitions
- Process standardization and efficiency initiatives
**Example Actions**:
- "Kill the SINGULARITY cron job (88 errors)" — Impact: Stops zombie compute spend — Source: COO — Time Estimate: 15 min
- "Route CTO build-readiness status to Marketing board, hold launch content in draft" — Impact: Prevents premature launch positioning — Source: COO — Time Estimate: Today

### 5. Design Advisory Board
**Lane**: User experience, visual design, interaction design, brand identity, design systems, accessibility, human-centered design, emotional impact
**Typical Outputs**:
- User experience flow and interaction recommendations
- Visual design specifications and brand guidelines
- Design system components and patterns
- Accessibility considerations and implementations
- Emotional impact assessments and feeling targets
**Example Actions**:
- "Increase vertical breathing room by 20% in response cards" — Impact: Creates more welcoming interface for health contexts — Source: Design — Time Estimate: 1 hour
- "Structure response cards with clear emotional hierarchy (reassurance first, details second)" — Impact: Improves user emotional state during health inquiries — Source: Design — Time Estimate: 2 hours

### 6. principal (Self-Identified or Stated Priorities)
**Lane**: the principal's own stated priorities, strategic direction, personal commitments, high-level decision making
**Typical Outputs**:
- Directly stated priorities from the principal
- Strategic direction updates
- Personal commitments and follow-ups
- High-level decisions requiring her input
**Example Actions**:
- "Review and approve the Better Sleep product scope definition" — Impact: Aligns on MVP functionality for first product to ship — Source: principal — Time Estimate: 45 min
- "Brief the principal's team on Better Sleep as the first build target" — Impact: Ensures engineering alignment on product direction — Source: principal — Time Estimate: 30 min

## How to Identify the Source
When reviewing upstream panel outputs:
1. Look for explicit action items or recommendations
2. Identify which advisory board produced the output
3. Match the action to the board's lane as described above
4. If an action requires the principal's direct decision or approval, source as "principal"
5. If an action crosses multiple boards, identify the primary owner or the board that initiated the recommendation

## Common Source Identification Patterns
- **Customer interviews, user research, opportunity assessment** → Product
- **Positioning, messaging, launch plans, audience targeting** → Marketing
- **Technical architecture, infrastructure, engineering priorities** → CTO
- **Operational processes, resource allocation, workflow optimization** → COO
- **User experience, visual design, brand identity, interaction flow** → Design
- **Directly stated priorities from the principal, strategic decisions** → principal
