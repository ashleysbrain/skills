# 2026-08-15 — Popper's dual-track falsification verdict (worked example)

The strategy under test: Project A (research hub zero-to-funded, structure-first, equity-sale oriented) + Project B (intelligent-OS essay), run in parallel.

## Kill-level gaps found

**G1 — Instrument inversion.** Project A optimized for equity sale, but every named door (ARC Prize, Schmidt Sciences, ARIA, NIH SBIR/STTR) is non-dilutive. Equity investors for a pre-revenue hub with zero publications, zero signed advisors, ~1 FTE do not exist. The plan built investor-grade structure to chase the least probable first money.

**G2 — The shell entity.** No microtask conveyed IP. All engines lived with the founder/parent. The hub would have formed empty: no IP assignment, no parent-hub license boundary, no cap table stub, no data room. Every diligence path dead-ends at "prove you own it."

**G3 — Zero evidence artifacts.** The plan scheduled structure and prose; nothing produced proof. First money follows evidence: a signed advisor letter (zero cost, highest leverage), a preprint of the lead asset.

**G4 — Firewall collapse question.** An investor reading both artifacts asks: "Which company am I funding — the metrics lab, or the OS you publicly say the market will REQUIRE?" Omission becomes concealment. Fix: one-line OS roadmap acknowledgment in the funding memo. "Market will REQUIRE" also fails the lab's own evidence gates — certainty claims get Tetlock-graded into probability + timeline language.

**G5 — Red-team placement.** Falsification AFTER construction is decoration. Pre-mortem moves BEFORE structure, scoped to cover economics and the tension rule itself.

**G6 — Parallelism tax.** Alternating dispatches halves both projects; both compete for the same solo-founder deep-work hours; the firewall guarantees the essay contributes nothing to first money. Serial A-then-B strictly faster.

**G7 — Malformed option set.** SPV is an investment vehicle, not an operating lab (category error). Missing options: fiscal sponsorship (fastest to grants) and plain standalone LLC.

## The rebuilt microtask sequence

- A0: Popper pre-mortem BEFORE structure (covers economics + tension rule)
- A1 fixed: instrument gate — fiscal sponsor (grant-first) vs subsidiary/standalone LLC (equity track); SPV dropped
- A1.5: IP assignment + parent-hub license + cap table stub + data room skeleton
- A2.5: advisor engagement letters FIRST (Anantua physics, Alterovitz clinical — zero cost, highest leverage)
- A3.5: preprint/technical report of the lead asset (legible to ARC/Schmidt)
- A6: grant mechanics — SAM.gov registration (weeks of lead time, start immediately), SBIR FOA scan
- Reorder: economics before pitch artifact; serialize A (1-2 weeks) then B

## Verdict
Dual-track as written: NO. Project A survives only as grant-first, IP-first, falsified-first.
