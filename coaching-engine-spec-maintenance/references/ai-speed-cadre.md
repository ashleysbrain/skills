## Key Monitoring Signals (Real-Time Alerts)

- Coaching completion rate drop >5% from baseline
- Scope boundary flags increase >10% from baseline
- Stagnant 8D scores for coached users over 7 days
- Mode-switching errors spike >15% from baseline
- User feedback NLP sentiment: confusion/dissatisfaction
- Repetitive coaching patterns detected
- Research integration pipeline stall >24h

## Escalation Path (Automated)

1. Continuous monitoring detects issue → auto-classifies severity
2. Minor: logged, queued for next hourly cycle
3. Moderate: flagged to the specialist engine immediately, fix within 2 hours
4. Critical: alert to DS SINGULARITY (principal proxy), remediation with the specialist engine within 30 min
5. Safety-critical: immediate halt of affected mode, principal notification, full incident review

## Versioned Persona System (DS HELM v1.0)

### Version Structure
- **Major (X.0)**: Architecture change — new frameworks, modalities, structural engine changes
- **Minor (X.Y)**: Capability expansion — new quality gates, research integrations, rubric recalibration
- **Patch (X.Y.Z)**: Fix — bug corrections, boundary tightening, parameter tuning

### Current Version: v1.0 (Genesis)
- Core frameworks: ACRF, RECF, TFACF, GAF, SMIF
- Quality gates: 4-mode rubrics operational
- Scope boundary: CEC v1.0 enforced
- Research pipeline: <24h velocity target
- Monitoring: Continuous + hourly + daily + weekly cycles

### Upgrade Protocol
1. **Proposal**: Guardian identifies need based on evidence/research/engine evolution
2. **Specification**: Define new frameworks, rubrics, capabilities, boundaries
3. **Validation**: Cross-agent review (the specialist engine, the specialist engine, Sage, HALO)
4. **Deployment**: Atomic swap — vN+1 replaces vN with rollback capability
5. **Verification**: 24-hour monitoring with enhanced metrics
6. **Lock**: Version locked, documentation updated, change log appended

### Persona Portability
- Each version is a complete artifact, instantiable independently
- Versions are comparable — A/B testing supported
- Rollback to previous version = single operation
- Version metadata travels with agent across deployments
