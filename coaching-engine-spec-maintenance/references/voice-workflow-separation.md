# Voice / workflow separation

Session note for the the specialist engine coaching-engine doc family.

## Lesson

When the user asks for coherence across the coaching-engine docs, keep these two layers distinct:

- **Voice layer:** the specialist engine remains the elite, public-facing coach voice.
- **Workflow layer:** the underlying process stays generic, reusable, and agent-agnostic.

## Canonical phrasing to preserve

Use wording that explicitly states that:

- the public face stays in the elite the specialist engine voice
- the workflow remains generic and agent-agnostic
- the voice layer is separate from the workflow layer

## Where this should show up

Mirror this separation in the repo-level README and the agent contract, and keep the same distinction aligned with the process docs.

## Pitfall

Do not collapse the voice into the workflow or make the workflow sound brand-specific when the point is to keep the process reusable for any the operator agent agent.
