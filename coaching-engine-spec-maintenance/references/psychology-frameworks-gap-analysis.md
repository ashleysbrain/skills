# Coaching Engine Psychology Frameworks — Gap Analysis and Knowledge Bank

Produced by an elite psychology panel (the specialist engine, the specialist engine, the specialist engine) with adversarial review by the specialist engine. Applies to ANY coaching engine that maps user situations to advice without pre-diagnosing motivation, capability, mindset, or friction.

## The Core Problem

Most coaching engines (including the the specialist engine Engine as of July 2026) commit the same error: they dispense advice without first diagnosing the psychological preconditions for action. They treat all users as if they have the same motivation type, same self-efficacy, same mindset, same behavioral friction. This produces advice that is informative but not actionable.

## Six Theoretical Domains to Integrate

### 1. Napoleon Hill — Mastermind and Definiteness of Purpose
- Every session opens with a **Purpose Lock**: confirm the user's single definite objective before generating advice.
- Hill, *The Law of Success* (1928); *Think and Grow Rich* (1937).
- Also grounded in goal-setting theory: Locke and Latham, *American Psychologist*, 2002.

### 2. Behavioral Physics — Momentum, Inertia, Friction
- Inertia: an object at rest needs activation energy.
- Momentum: once moving, per-step effort decreases.
- Friction: contextual barriers dissipate momentum.
- Assign a **Friction Score** (1-5) to each action; auto-generate friction-reduction steps.
- Nevin, "Behavioral Momentum," *Behavioral and Brain Sciences*, 1988.
- Wood and Neal, "A New Look at Habits," *Psychological Review*, 114(4), 2007.

### 3. Synergy Science
- Cognitive diversity beats individual ability on complex problems (Page, *The Difference*, Princeton, 2007).
- Complex situations should compose 2+ advisor perspectives that are integrated, not listed.

### 4. Fogg Behavior Model — B = MAP
- Behavior = Motivation x Ability x Prompt. All three required simultaneously.
- Run a **MAP Check** before every action step: motivation sufficient? ability staged? trigger specified?
- Fogg, *Tiny Habits* (HMH, 2019).

### 5. Self-Determination Theory (SDT)
- Autonomy, Competence, Relatedness are the three psychological needs.
- Coaching language must be autonomy-supportive ("You might consider...") not directive ("You must...").
- Deci and Ryan, "The 'What' and 'Why' of Goal Pursuits," *Psychological Inquiry*, 11(4), 2000.

### 6. Positive Psychology — PERMA and Flow
- PERMA: Positive emotion, Engagement, Relationships, Meaning, Accomplishment (Seligman, *Flourish*, 2011).
- Flow: match challenge to skill level (Csikszentmihalyi, 1990).

### Neuroscience Additions
- Neuroplasticity: Doidge, *The Brain That Changes Itself* (Viking, 2007).
- Dopamine prediction error: Schultz, "Predictive Reward Signal of Dopamine Neurons," *Journal of Neurophysiology*, 1998. Structure variable-reward milestones.

## Wave Engine v2 Architecture (11-Step Pipeline)

```
Step 0:  PURPOSE LOCK (Hill) — confirm definite objective
Step 1:  SITUATION CLASSIFIER — 9 types + complexity score
Step 2:  MOTIVATION DIAGNOSIS (SDT) — intrinsic to external
Step 3:  SELF-EFFICACY CALIBRATION (Bandura) — 1-5 staging
Step 4:  MINDSET DETECTION (Dweck) — growth/fixed signals
Step 5:  SYNERGY PANEL COMPOSITION — 1 voice simple, 2+ complex
Step 6:  COACHING GENERATION — growth-language, autonomy-supportive
Step 7:  MAP CHECK (Fogg) — motivation + ability + prompt
Step 8:  FRICTION SCORE + REDUCTION — 1-5 + auto sub-step
Step 9:  IF-THEN PLAN (Gollwitzer) — trigger to action
Step 10: DOPAMINE MILESTONES — variable-reward checkpoints

Optional layers: Pre-Mortem, PERMA Scan, Flow Calibration, Incubation
```

## Tiered Implementation Priority

- **Tier 1 (validated science, implement first):** SDT motivation diagnosis, Fogg MAP check, Gollwitzer If-Then plans, Bandura self-efficacy, Dweck mindset language, Kahneman loss-aversion framing.
- **Tier 2 (practitioner frameworks, implement second):** Hill purpose lock, Covey/Page synergy composition, Seligman PERMA scan.
- **Tier 3 (measurement and iteration):** Falsifiability hooks, effect-size tracking, Popper corrective.

## Adversarial Review Notes (Popper Pattern)

When applying these frameworks, run a falsifiability check:
1. **Conflation risk:** Hill, Covey, and "behavioral physics" metaphors are practitioner frameworks, not empirically validated science. Label them as such. SDT, prospect theory, mindset research, and Fogg have stronger empirical bases.
2. **Construct validity:** Any score (Friction Score, MAP Check) needs an operationalized measurement instrument before deployment. Ground in SRHI (Wood and Neal, 2007) for friction.
3. **Replication concern:** Growth-mindset effects vary by population (Sisk et al., 2018, *Psychological Science*). Target the language layer, not universal performance gains.
4. **Demand characteristics:** Do not surface psychology labels in every coaching utterance. Put them in a meta-layer the user can access if they want.
5. **Over-engineering risk:** Gate diagnostic layers behind complexity scoring. Simple everyday tasks should skip Steps 2-4 and go directly to action.
