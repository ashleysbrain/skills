## What PIML Means for Divinity Health

**Physics-Informed Machine Learning** = ML algorithms bounded by real physical, biological, and psychological constraints. Not just fitting statistical models to data.

### The Core Distinction

| Traditional ML | PIML (Our Approach) |
|----------------|---------------------|
| Fits statistical patterns to data | Respects how systems actually work |
| Learns correlations from history | Encodes mechanistic constraints (ODEs, PDEs, conservation laws) |
| Black box | Interpretable, bounded by physics |
| Can hallucinate impossible states | Cannot violate physical/biological laws |
| Needs massive data for accuracy | Works with sparse data + strong priors |

### What "Physics-Informed" Concretely Means for Human Behavioral Health

The algorithms are constrained by real biological and psychological dynamics:

- **Sleep pressure** — Homeostatic + circadian dynamics (two-process model)
- **Stress hormones** — HPA axis dynamics, cortisol cycling
- **Cognitive load** — Working memory capacity, executive function depletion curves
- **Behavioral change** — Transtheoretical model stages, habit formation kinetics
- **Coupling between dimensions** — How sleep tugs on stress, stress on cognition, etc.

The physics *constrains* the model, which means the coaching respects reality, not just patterns.

**Why this is defensible:**

1. **Nobody else does this for wellness.** PhysicsX ($2.4B valuation) applies PIML to industrial systems. Divinity Science is first for human behavioral health.

2. **Hard to replicate.** Requires: deep physics/math expertise + behavioral science + 8,400+ lines of production Python + coupling matrix architecture + deterministic rescore engine.
