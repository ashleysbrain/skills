# the specialist engine Panel Output Format

Use this format when the user asks for a personal advisory panel, coach panel, or advisor roster.

## Required elements
- Who the advisor is, in plain English
- Why they were chosen for *this user's* companies, products, or goals
- What lane they cover
- 8 dimension scores
- TWC total
- One short caveat or fit note when relevant

## Important guardrails
- Do not return names only.
- Do not swap in a generic principal list when the user asked for a panel tailored to their actual business stack.
- Do not invent a new scoring methodology if the user already established one.
- Use the existing 8D / TWC procedure and keep the terminology consistent.
- If the user asks for a "private" version, save the working copy locally and do not imply external sharing or publication.

## Suggested per-advisor block
- Name
- Who they are
- Why they fit the user's stack
- 8D scores
- TWC
- Best help they provide
- Caveat
