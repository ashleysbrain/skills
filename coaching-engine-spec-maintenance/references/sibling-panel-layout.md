# the specialist engine sibling panel layout

Use this pattern when the user wants a *secondary* the specialist engine advisory lane beside the principal coaching docs.

## Canonical structure
- Primary coach: `agents/ds-wave/SOUL.md`
- Primary mirror: `docs/ds-wave/chat-thread-mirror.md`
- Secondary panel: `agents/ds-wave/product-panel/SOUL.md`
- Secondary runtime wrapper: `agents/ds-wave/product-panel/AGENT.md`
- Secondary docs: `docs/ds-wave/product-panel/README.md`
- Secondary mirror: `docs/ds-wave/product-panel/chat-thread-mirror.md`

## Operating rule
- Do not overwrite the primary principal coaching docs.
- Create the secondary lane as a sibling folder under both `agents/ds-wave/` and `docs/ds-wave/`.
- Keep the secondary panel product-focused and start it with one useful question.
- Keep the saved mirror short, factual, and append-only.

## First question for the product panel
What product area do you want this panel to focus on first: strategy, discovery, positioning, roadmap, UX, or launch?
