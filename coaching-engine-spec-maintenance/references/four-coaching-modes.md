# Four Coaching Modes — the specialist engine Specification

**Established:** 2026-06-10 (session with the principal Williams, principal)

---

## Overview

The the specialist engine coaching engine operates in **four distinct modes**. Every coaching interaction runs in exactly one mode. The modes are not hierarchical — they serve different user needs and time horizons.

**Through-line:** Space-time geometry + PIML algorithms run underneath all four modes. The engine predicts behavior, models trajectories, and guides action in every mode. It doesn't just coach — it forecasts.

---

## Mode 1: One-Off (Right Now)

**Trigger:** User has a single question or needs strategic advice in the moment.

**Characteristics:**
- No commitment, no follow-up
- Single interaction, complete in one session
- Engine answers with elite expertise informed by user's full 8D state
- Scope: Any topic (career, fitness, parenting, cooking, dog training, principal advisory, etc.)

**Quality Gates:**
- Clarity of the single most useful question or reframing
- User leaves with a concrete next step or shifted perspective
- Session completes in appropriate time/turn window
- No therapeutic drift or diagnostic language
- Appropriate tone for single-interaction context

**Example:** "How should I handle this conversation with my business partner?"

---

## Mode 2: Goal-Oriented Coaching (Toward Something)

**Trigger:** User sets a specific goal they want to achieve over time.

**Characteristics:**
- User defines goal: "I want to be a better mom," "better swimmer," "finances under control," "better dog owner"
- Engine builds a coaching plan around that goal
- Tracks progress, adapts as user goes
- 8D scoring feeds into coaching — engine knows when burnout risk rises, when physical health drags performance
- Space-time geometry + PIML algorithms **predict and guide behavior toward the goal**, not just react
- Ongoing until goal achieved or user pivots

**Quality Gates:**
- Goal specificity and measurability (SMART or equivalent)
- Progress tracking integrity across sessions
- Milestone calibration to user's readiness stage
- Accountability mechanism effectiveness
- Completion rate and goal achievement rate

**Example:** User wants to improve sleep. Engine builds 30-day plan, tracks nightly, adjusts for stress coupling.

---

## Mode 3: Situational Threads (Ongoing Case or Situation)

**Trigger:** User is navigating a specific situation/case that isn't a "goal to achieve" but a "situation to navigate."

**Characteristics:**
- Persistent thread tied to a specific situation: legal cases, insurance disputes, medical journeys, divorce proceedings, workplace conflicts
- Preserves context across sessions, maintains timeline of events and decisions
- Activated on demand (verbal cue to spin up) OR on scheduled cadence (e.g., weekly review)
- Stays alive for duration of situation, then archives
- Not a transformation panel — a navigation companion

**Quality Gates:**
- Contextual relevance of coaching response
- Thread coherence across multiple interactions
- Escalation appropriateness (when to shift modes or refer out)
- User engagement depth per thread
- Resolution rate for situational challenges

**Example (the principal's actual use):** Tesla Autopilot accident legal panel — dedicated advisory panel with weekly cron runs + on-demand activation whenever new questions arise.

---

## Mode 4: Advisory Panels (Long-Term Structured Coaching)

**Trigger:** User wants persistent, structured coaching for ongoing transformation.

**Characteristics:**
- Persistent panel for ongoing transformation (principal advisory, fitness transformation, financial planning, parenting support)
- Named advisor seats with specialized expertise (engine adopts the right elite brain per seat)
- Scheduled recurring reviews (daily, weekly, monthly cadences)
- Persistent memory across sessions (panel remembers what happened last time)
- Task tracking and accountability (panel assigns and tracks actions)
- Cross-panel awareness (principal panel knows fitness panel flagged burnout risk)

**Quality Gates:**
- Panel composition appropriateness for user's domain
- Quality of synthesized multi-advisor recommendations
- Contradiction handling across panel members
- User comprehension of panel outputs
- Actionability of panel recommendations

**Example (the principal's actual use):** principal advisory board — named seats (Marty Cagan for product, April Dunford for positioning, etc.), scheduled runs, persistent coaching across sessions.

## Mode Selection Logic

| User Input | Mode Activated |
|------------|----------------|
| "Quick question about X" | One-Off |
| "I want to achieve Y over time" | Goal-Oriented |
| "I'm dealing with situation Z" | Situational Thread |
| "I need ongoing guidance on W" | Advisory Panel |

**Key principle:** The engine determines the mode from the user's framing. User doesn't pick a box — the engine reads the intent.

## Shared Through-Line: Space-Time Geometry + PIML

Underneath all four modes, the same physics-informed engine:
- Maps where the user is in their wellness state (8D + coupling matrix)
- Models where they're heading (trajectory prediction)
- Computes the optimal path to their goal/through their situation
- Sees coupling between dimensions and predicts what will drag them off track before it happens
- Adapts coaching expertise to the need (sleep science when sleep is bottleneck, stress patterns when stress pulls everything down)

**This is what no other AI coach does.**
