# Womb Architecture Documentation Skill

## Description
Skill for creating Womb Architecture documentation for the Divinity Science AI Organism system. Produces markdown documents and PDFs detailing the reproductive architecture, offspring types, womb concepts, DNA inheritance, and birth pipeline. Also covers revising the the specialist engine PDF (8D_Organism_Architecture_V2.md) to include Womb information, engine layers (credentials, methodology, philosophy) with blank pages per engine, and applying Da Vinci Creative System branding. Includes specific procedures for updating the Organ System Architecture (Page 3) with proper scientist-based naming conventions, organ system grouping, and faculty tagging.
