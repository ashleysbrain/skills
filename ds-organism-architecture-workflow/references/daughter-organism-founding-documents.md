# Daughter-organism founding documents (values, philosophy, identity)

Use this reference when writing founding documents (values, philosophy, mission, about, company identity) for a Divinity Science daughter organism or subsidiary brand. Daughters include Divinity Health, Constellation, the the operator agent organism family, 8D360AI, Qubit, Goddess Divinity, and future forks.

## Why this is a distinct pattern

A daughter's founding document is not free creative writing. It is a **genome expression document**: it inherits binding chromosomes from DS BRAND-DNA and expresses them through the daughter's phenotype. Values invented from scratch drift from the parent's actual philosophy within one paragraph. Values grounded in the real source documents stay coherent and defensible.

Before drafting ANY daughter founding document, read the actual ecosystem sources. Do not write from memory of what DS "probably believes." Read:

1. **The genome** — `/<workspace>`, full read. Chromosomes 1 (Identity: brand hierarchy, naming, product phenotype model), 3 (Voice DNA), 4 (Philosophy DNA: Buddhism/peace/non-violence, allostasis, free energy, wisdom principles, ethics), 8 (Legal/Compliance: IP, consent, security), 11 (Evidence hierarchy, citation standards, scientific method). These are the binding inheritance.
2. **Research integrity canon** — `organism/VERITAS-SCOPE-AUDIT-R2-hermes.md` (the falsification-gate decisions: survivorship not truth, thymic medulla anatomy, temporal decay) and `hydra-os/intel/research-department/RESEARCH-INTEGRITY-PROTOCOL.md` (anti-hallucination safeguards, citation verification, multi-angle triangulation, credibility scoring).
3. **The daughter's own product spec** — check `docs/womb-architecture/*PHENOTYPE_SPEC*.md` or the daughter's own directory (e.g., `docs/constellation/`) for the phenotype expression profile. The phenotype defines which chromosomes are amplified vs suppressed for this organism.

## The five-section structure (proven)

A daughter founding document covering values plus philosophy should include:

1. **Core values (5-7).** Each stated as the BEHAVIOR it forces, not the feeling it evokes. One line explaining what it means IN PRACTICE. Example: "Physics drives decisions, it never decorates them" with a concrete "if you cannot state the free-energy calculation, the work is not ready to start." Abstract values ("Integrity," "Excellence") are rejected on sight.
2. **Philosophy on AI and human intelligence.** The organism-not-tool stance, biological isomorphism, human-decides/AI-advises, mastermind synergy, creativity as biological.
3. **Stance on open science.** What is open (frameworks, published research, scoring transparency) vs what is proprietary (engine code, detection algorithms, methodology IP). The "give away the map, sell the compass" principle.
4. **Research integrity and ethics.** Anti-fabrication (citation verification non-negotiable), multi-angle validation, falsifiability requirement for all claims and guarantees, four medical ethics principles adapted, temporal honesty (claims decay).
5. **Relationship to Divinity Science (parent).** Daughter organism, own brand, "Powered by DS" badge, inherits core chromosomes (Ch1 Identity plus Ch4 Philosophy) bindingly, expresses own phenotype, feeds learnings back. The inheritance is binding; the expression is ours.

## Hard rules specific to daughter founding docs

- **Never invent values that contradict the genome.** If a value sounds like it could come from any generic startup (Innovation, Customer-First, Excellence), it is wrong. DS values carry physics, falsification, allostasis, and the body-as-technology worldview.
- **Products have their OWN brand.** Never call a daughter "a Divinity Science product." The relationship is marked by "Powered by Divinity Science" in footer/signature only. DS is the parent referenced in the badge, like Intel Inside.
- **Survivorship is the credential, not truth.** When writing about research integrity, the VERITAS gate means a claim has FAILED TO BE KILLED, not been proven true. "Verified" is a word we do not use about our own outputs.
- **"Insufficient evidence" is a finished answer.** Never manufacture certainty. The honest "we do not know yet" is acceptable and publishable.
- **No AI tells.** No emoji, no em dashes in body text, no "reaching out" or generic corporate language. The voice is evidence-based, direct, precise, warm without saccharine. See genome Ch2.5 and Ch3.
- **Cite the genome as authority.** End with a governance line: the genome is authoritative where this doc and it conflict on core identity/philosophy; this doc governs where it adds phenotype specificity.

## Pitfall: values as abstract words

The most common failure mode. "Integrity. Excellence. Innovation. Collaboration." — these are worthless because they force no behavior and could appear in any company's deck. The fix: state each value as a testable rule. "A number that does not force a decision is deleted" is a value. "Data-driven" is not. If you cannot write the "in practice" line, the value is too abstract to keep.

## Pitfall: treating the parent relationship as optional framing

Daughters inherit the specialist engine 1 and 4 without modification. The worldview (interdependence, impermanence, compassion in action, non-attachment to outcome), wisdom principles, and physics principle are genetic core that cannot be contradicted. Everything else is tunable to the daughter's domain. Get this boundary wrong and the document either under-claims (ignoring the inheritance) or over-claims (contradicting the parent).
