## The Selection Math (DNA-Encoded)

Every approach/philosophy is scored deterministically before the consortium
applies it. The selection function IS the DNA — it determines what gets
expressed.

### The Scoring Formula

```
Score(P, T) = 0.30*DNA(P) + 0.25*EIGHT_D(P) + 0.20*FIT(P,T) + 0.15*EVIDENCE(P) + 0.10*CONTRARIAN(P)
```

### Free Energy Gate (ratio, not difference)

```
F = COST / [Score * (1 + INFO_GAIN)]
F < 1.0 → ADMIT (value exceeds cost)
F >= 1.0 → SKIP (cost exceeds value)
```

Calibrated as a RATIO gate to avoid scale mismatch between cost (0.1-0.7) and
score (0-1). A difference gate (F = cost - value) was initially used but
rejected everything because of the scale mismatch.
