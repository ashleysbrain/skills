# Concurrent-blind panels (principal directive 2026-08-23: "concurrent not in concert")

When to use: principal orders cross-angle convergence hunting — "thorough security
from same and different angles", "10+ brains, concurrent not in concert",
multi-angle gap hunts. NOT for verdicts that must build on each other
(R1/R2, falsifier->consolidator chains — those stay sequential
chain-of-custody).

## Pattern (proven, deleg_55c74836 + deleg_161b4570)

1. Seats run BLIND inside ONE sequential child (429 law still governs —
   never parallel elite children; "concurrent" = no cross-reading, not
   parallel dispatch).
2. Each seat appends to the SAME review file under its own header
   ("## SEAT A — <name>"), one write at end of its run. Concurrent-safe.
3. No seat sees another's output. Each gets the same evidence pack +
   full persona spec + its own ANGLE (attack-tree, benchmark-map,
   maintainability, cleanse-discipline, middle-out architecture, etc.).
4. CONVERGENCE ANALYSIS IN THE PARENT after all land: gaps flagged by 2+
   independent blind methods = ground truth. Proven instance: 3 seats
   (Schneier attack-tree, Darwin maintainability, NIST-CSF mapping)
   independently found the missing DETECTION plane — that finding carried
   the panel's highest confidence and drove the P0 task mint.

## Why it works

Sequential chain-of-custody propagates one seat's framing error into all
downstream seats. Blind seats fail independently; agreement across blind
methods is correlation of reality, not of narrative. This is the panel
analog of the Cross-Model Critic law (family-diversity defeats correlated
blind spots) applied WITHIN a panel.

## Rotation rule

principal preference: rotate brains between passes — no seat repeats a prior
pass's persona-mode pairing on the same subject (QA #1 Popper/Unna/Deming
-> QA #2 Sherrington/Cannon/Semmelweis/Fustir/Tanenbaum, etc.). Fresh
angles, fresh names, same discipline.

## Sizing note

Keep seats to ~5 SHORT tool calls and one <350-word final pass (short-output
rule applies). Convergence value comes from independence, not verbosity.
