# General-User Repo vs Personal Persona Boundary

## Pattern
When a repository or shared product line is meant for general users, keep the repo-facing agent neutral and reusable.

## Example from this session
- `the specialist engine` stays as the general-user primary coach name.
- A principal-specific narrow field does **not** belong in the general-user repo.
- Personal principal-coach traits should live outside the repo in a separate user-scoped profile or artifact.

## Rule of thumb
- Keep the shared engine general.
- Keep the personal specialization separate.
- If a brand name must stay for continuity, strip the narrow role from the repo artifact and preserve only the general coaching identity.
